# AI虚拟产品全链路作战系统 - 使用指南

## 这套系统能帮你做什么

一句话：**选品、做品、写笔记、出单，一个人用AI跑通全链路。**

系统分4层，从最重要的往下：

| 层级 | 解决什么问题 | 对应目录 |
|------|------------|---------|
| 战略决策 | 选什么品？方向对不对？要不要换？ | `01.我的战略/` |
| 能力扩展 | 写笔记、做产品、搓工具 | `02.参考方法论/` + `03.我的弹药库/` + `05.我的产品/` |
| 灵感捕捉 | 碎片想法自动归集，不再丢灵感 | `04.我的输入/` |
| 效率提升 | 排版、整理、同步，一句话搞定 | skills自动执行 |

---

## 核心概念

### CLAUDE.md = AI认识你

vault根目录的 `CLAUDE.md` 是整套系统的灵魂。Claude Code每次启动都会自动读取它。

你在里面写清楚：你是谁、卖什么、卖给谁、你的优势、你的写作风格。

**AI给你的所有建议，全部基于这个文件。** 不是通用废话，是结合你的产品、你的用户、你的阶段给的判断。

填好CLAUDE.md是你要做的第一件事。

### Skills = 一句话触发的能力模块

系统内置了30个skill，每个解决一个具体问题。你不需要写复杂的提示词，直接跟AI说人话：

- "帮我做客户画像" → 自动调用精准客户画像skill
- "帮我分析这篇笔记" → 自动调用爆款结构分析skill
- "帮我写商品笔记" → 自动调用商品笔记写作skill

### Vault = 你的知识库会越用越强

每次skill跑出来的结果都存在vault里。下次AI写内容时，会自动读取这些历史数据。

用得越多 → 沉淀越厚 → AI推荐越准 → 下一次起点更高。

## 目录结构说明

```
00.新手入门/     你现在在看的地方，看完就可以删
01.我的战略/     定位、选品、决策复盘 —— 方向性的东西放这里
02.参考方法论/   12篇通用方法论文档，所有人一样
03.我的弹药库/   skill产出的个人数据（画像/关键词/情绪洞察等）
04.我的输入/     所有碎片、采集、笔记的入口
05.我的产品/     选品→做品→包装→商品笔记
笔记同步助手/    手机端同步入口
飞书同步脚本/    飞书碎片同步到OBS
.claude/skills/  所有skill文件，开箱即用
```

| "帮我做客户画像" | 精准客户画像 | 3个精准人群画像 |
