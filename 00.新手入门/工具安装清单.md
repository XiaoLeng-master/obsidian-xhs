# 工具安装清单

> 基础工具（Obsidian、Node.js、Claude Code、插件）已通过一键脚本安装完毕。以下是按需选装的工具。

## 选装（按需安装）

### 1. lark-cli（飞书命令行工具）
- 飞书同步脚本的核心依赖，必须先装这个
- 安装方式：打开终端，运行以下命令：
  ```
  npm install -g @larksuite/cli
  ```
- 安装完后初始化配置：
  ```
  lark-cli config init
  ```
  按提示填入你的飞书应用 `app_id` 和 `app_secret`（创建飞书应用的步骤见 [[飞书同步脚本/飞书同步配置]]）
- 验证安装成功：
  ```
  lark-cli --version
  ```
- 如果遇到问题，跟AI说"帮我安装 lark-cli"

### 2. 飞书同步脚本
- 位置：`飞书同步脚本/`（vault根目录下）
- 功能：飞书机器人消息 → 自动同步到OBS
- **前提：先装好 lark-cli（上面第1步）+ 创建飞书应用并开启机器人能力**
- 详细配置步骤见 [[飞书同步脚本/飞书同步配置]]

### 3. 微信笔记同步助手
- 功能：微信转发内容 → 自动同步到OBS
- 配置方式见教程

## Claude Code 登录说明

Claude Code 安装后需要登录一次才能使用，有两种方案：

**方案A：Claude 官方订阅（推荐，效果最好）**
- 闲鱼搜「Claude Max 代充」购买月付订阅
- 启动 Claude Code 后选择「Claude account with subscription」
- 浏览器弹开后点 Authorize（授权）
- 回到终端看到 Claude Max 字样 = 成功

**方案B：第三方 API（按量付费，更便宜）**
- 推荐 openclaw-api.com，20元起步
- 注册、充值、创建 API Key
- 打开 Obsidian → 设置 → Claudian → Environment Variables
- 填入 `ANTHROPIC_API_KEY` 和 `ANTHROPIC_BASE_URL`
