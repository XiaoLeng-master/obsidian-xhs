# AI提示词库

> 高频使用的AI提示词，按场景分类。
> 可直接复制使用，也可以作为灵感自己修改。

---

## 产品设计类

### 需求分析
```
我有一个产品想法：[描述想法]。
请帮我分析：
1. 目标用户是谁？
2. 核心痛点有多痛？
3. 现有方案的不足在哪里？
4. 我的差异化机会是什么？
5. 最大的风险是什么？
```

### 竞品调研
```
我想做[产品类型]，请帮我做横纵分析：
- 纵向：这个领域的发展历史和趋势
- 横向：当前主要竞品及其优劣势
- 交汇：我的切入机会和风险
```

### MVP 定义
```
我的产品要解决[问题描述]。
请帮我定义 MVP：
1. 只保留什么功能？（砍掉什么？）
2. 第一版需要什么技术？
3. 2周内能做出什么？
```

## 开发类（专业模式）

### 代码生成
```
请帮我写一个 [功能描述] 的 Go 代码。
要求：
- 遵循项目目录结构（internal/handler、internal/service、internal/repository）
- 包含错误处理
- 包含必要的注释
- 考虑边界情况
```

### 代码审查
```
请审查这段代码的逻辑漏洞、性能问题和安全隐患。
```

### 数据库设计
```
根据这个产品方案，帮我设计数据库表结构。包括核心表和索引。
```

### Bug 排查
```
我遇到了一个问题：[描述现象]
- 复现步骤：
- 期望行为：
- 实际行为：
- 相关日志：
请帮我分析可能的原因和排查思路。
```

### 重构建议
```
这段代码目前的问题是[描述]。请给我3个重构方案，说明各自的优缺点。
```

## 学习类

### 新技术入门
```
我想学[技术名称]。我的水平是[描述]。请给我一个7天的学习路线图。
```

### 概念理解
```
请用通俗的方式解释[概念]，然后用一个具体例子说明。
```

## 写作与推广

### 技术文章
```
我最近做了一个[项目/功能]。请帮我写一篇面向[目标读者]的技术分享文章。
```

### 产品发布文案
```
我的产品[名称]要发布了。核心功能：[功能]。差异化：[特点]。请帮我写发布文案。
```

## 效率类

### 自动化脚本
```
我经常需要做[重复操作]。请帮我写一个脚本自动化。
```

### 命令生成
```
我想用 [工具] 完成[任务]，帮我生成命令。
```

---

> 💡 **使用技巧**：
> - 提示词越具体，AI 的输出越精准
> - 加上你的上下文（技术水平、项目背景），效果更好
> - 不满足的输出，追问比重写更高效
> - 每次用了一个好用的提示词，考虑加到这个库里
