# Frontmatter 规范

> 统一本知识库中所有 Markdown 文件的 YAML frontmatter 格式。

## 基础字段

```yaml
---
title: 文件标题
date: 2026-05-28
tags: [标签1, 标签2]
status: draft | in-progress | completed | archived
---
```

## 按目录的推荐标签

| 目录 | 推荐标签前缀 |
|------|------------|
| 02.创意花园 | `#想法` `#灵感` |
| 03.深度调研 | `#调研` `#竞品分析` `#市场` |
| 04.产品设计 | `#产品设计` `#技术方案` |
| 06.构建工坊 | `#脚手架` `#代码片段` `#提示词` |
| 07.项目管理 | `#项目/[项目名]` |
| 08.反馈与迭代 | `#复盘` `#bug` `#反馈` |
| 09.方法论沉淀 | `#踩坑` `#最佳实践` `#原则` |
