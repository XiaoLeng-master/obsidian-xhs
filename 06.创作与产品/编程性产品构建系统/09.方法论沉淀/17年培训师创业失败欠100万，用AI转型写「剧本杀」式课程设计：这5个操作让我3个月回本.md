### 三）为什么选剧本杀这个赛道



选剧本杀，不是因为它有多新鲜，是因为它是最适合我的一条路。



**1、离培训最近**

剧本杀本质上是一个"沉浸式学习"的场景——玩家不是被动听故事，而是主动代入角色，在冲突中做出选择，在选择中理解道理。这比坐在下面听讲强一百倍。

培训行业缺的从来不是内容，缺的是让学员真正参与进来的形式。剧本杀天然就是干这个的。



**2、AI把门槛打下来了**

以前做一个定制剧本杀，3-5人专业团队花30人天来做，一个人是不可能完成的任务。现在用AI，我一个人两天搞定，成本接近于零。而且契合了AI破局俱乐部我参加的林杰教练组织的OPC概念。



**3、差异化够强**

TTT课程从1万5卷到8000块，培训师们互相压价。市场上会讲AI工具的人很多，但能把AI工具和游戏化教学结合、真正交付"学员玩得嗨、学得深、记得住"的培训师，凤毛麟角。 **这就有了溢价空间。**



**4、时间投入：每周不到20小时**

我现在大部分时间还是讲课，剧本杀这件事，主要靠AI工具在驱动，每周投入不超过20小时。

## 四、这个项目AI改变了什么



**AI能帮你写剧本。**

我把自己的一门管理课拆解成剧本杀框架，然后让AI帮我生成剧情、角色卡、机制测试……来回改了三四版，一个完整的剧本杀初稿就出来了。整个过程，我一个人，两天。 **成本：接近于零。**



你可能会问：AI写的剧本，质量能过关吗？

AI写的初稿确实不能直接用——语言太干，缺乏情感，逻辑有时候会跳。但它帮我解决了最耗时的部分： **①从0到1的脑洞和创意 ②剧本细节创作 ③素材设计制作(生课件生图生视频)。** 剩下的精细化调整、结合课程内容的定制判断、线下试跑后的迭代——这些还是我来。



**AI不是替代你，而是放大你。** 它帮我把"想得到但做不了"的事情变成了现实。

## 五、我是怎么做的（完整复盘）



> **先说清楚一件事**

> 培训师做剧本杀课程，跟娱乐行业的剧本杀是两码事。

> ❌ 我们不是教"怎么写剧本杀"——那是娱乐产品

> ✅ 我们是教"怎么用剧本杀的形式做教学设计"——教学目标是目的，游戏是手段

> **记住这句话，后面的所有步骤都围绕这个逻辑展开。**

### 一）采集需求，定位场景



#### **1、先想清楚「教什么」，再想「怎么玩」。**



做剧本杀课程，第一步不是写剧本，是搞清楚你要解决什么问题。很多培训师一上来就想"我要做一个剧本杀"，但没想清楚 **"我要让学员学到什么" —** —结果做出来的剧本杀很好玩，但学员学不到东西。

所以第一步，是回答这6个问题：

| 信息项 | 我是怎么回答的 |
|-|-|
| 这门课讲什么？ | DISC四种人格类型的时间管理策略 |
| 学员学完能做什么？ | 能识别自己和对方的性格类型，做出更有效的时间决策 |
| 谁来参加？ | 企业中层管理者，20人左右，30-45岁，多数没玩过剧本杀 |
| 游戏部分多长？ | 半天（3-4小时） |
| 学员最大的困难是什么？ | 总是用自己的逻辑去管理所有人，不知道因人而异 |
| 剧本什么氛围？ | 职场场景，真实感强 |

这6个问题的答案，就是后续所有设计的基准。



**需求采集完了，下一步选场景原型。**

剧本杀课程有10种场景原型：

| 场景原型 | 适用课程类型举例 |
|-|-|
| 谈判博弈 | 商务谈判、沟通技巧、销售 |
| 危机决策 | 危机管理、领导力、合规风控 |
| 商业竞争 | 市场营销、项目管理、创业 |
| 历史事件 | 历史、文学、企业文化 |
| 侦查推理 | 审计、法学、刑侦 |
| 团队生存 | 团队建设、领导力、沟通协作 |
| 科技/未来 | 数字化转型、AI应用 |
| 社会/公共 | 公共管理、政策分析 |
| 文化/伦理 | 企业文化、职业道德 |
| 创新/设计 | 创新思维、产品设计 |

#### **2、让AI出10个方案，我来挑1个最喜欢的。AI负责发散，我负责选择。**



很多培训师卡在这一步——脑子里有一个模糊的想法，但不知道从哪里下手。AI创意爆破就是解决这个问题的：让AI帮你想10个方案，你只需要挑1个。

**工具：ChatGPT / Kimi / DeepSeek 任意AI对话工具**

提示词：

```Plaintext
我正在设计一门关于【DISC时间管理】的剧本杀课程。
我选择的场景原型是【团队生存】。
请帮我生成8-10个具体的场景创意方案。
每个方案包含：
- 场景名称（≤10字）
- 一句话背景设定
- 核心冲突（两难困境）
- 至少6个角色建议（含角色名+立场+性格）
- 信息差设计

要求：贴近【中层管理者】真实认知，冲突有两难性质，角色信息不对称且互相依赖。请先出8个，我再筛选。
```



AI给我的方案里，有几个让我眼前一亮：

- 方案A：家族企业传承，两代人权力交接
- 方案B：创业公司倒闭前，4个部门负责人各自为战
- 方案C：疫情封城下的资源分配困境

我选了 **方案B——创业公司濒临倒闭前的决策困局。** 为什么？



> 一家创业公司资金链断裂，CEO必须在48小时内做出决策：是砍掉哪个部门，还是全员降薪，还是引入外部投资。4个部门负责人各有立场，每个角色代表一种典型的人格类型。玩家需要通过谈判、交易、信息交换，最终达成"让公司活下去"的目标。



**这个场景完美匹配我的课程：**

- DISC 的每种人格类型对应一个部门负责人
- "让公司活下去"的目标天然创造两难困境（D型要快刀斩乱麻，S型要顾全情绪，C型要看数据，I型要看人心）
- 每个角色都有信息不对称，天然产生谈判需求



> 💡 **筛选方案的原则：** 删掉跟学员无关的、角色太扁平的、冲突不是两难的。保留2-3个最好的让用户选。

### 二）把知识点藏进线索，把任务埋在剧本



#### **1.知识点不能贴标签，要让学员在情境中自己"发现"。**



这一步是最关键的一步，也是最容易被忽视的一步。

很多培训师做剧本杀，犯的最大的错误是： **把知识点直接写在剧本里，** 让角色直接说"我们来学习DISC理论吧"——这跟直接讲PPT没有区别。



正确的做法是：把你的课程知识点，翻译成剧本杀里的"线索"，让学员在玩的过程中自己发现规律。

这一步用的是HKP模型，翻译成大白话就是：



| HKP模型 | 含义 |
|-|-|
| H（Hidden） | 你要教的知识点是什么？ |
| K（Key） | 这个知识点长什么样？（用什么信息载体呈现？） |
| P（Practice） | 学员拿到这个信息后，要做什么选择？ |



**工具：ChatGPT / Kimi / DeepSeek**

**提示词：**

```Plaintext
我有一门课程，关于【DISC时间管理】，包含以下3个核心知识点：
1. 沟通方式因人而异——不同性格的人，接受信息的偏好不一样
2. 决策风格决定行动效率——D型追求速度，S型追求稳定，C型追求精准，I型追求认同
3. 时间管理优先级不同——不同性格的人，对"重要的事"定义不一样

请用HKP模型帮我翻译每条知识点。具体格式如下：
H（Hidden）: 你要教的知识点是什么？
K（Key）: 这个知识点用什么样的【信息载体】呈现？（文件/邮件/合同/口供/物品等）
P（Practice）: 学员拿到这个信息后，要做什么选择？跟谁互动？

请为每条知识点生成：知识描述+场景设定+角色信息+线索名称+全文内容。
```

#### 2.AI解决从0到1的框架问题，人来赋予"灵魂"。

线索设计完了，下一步是写角色卡。这是整个流程里最耗时的一步，也是AI帮我省力最多的一步。

**角色卡用的是三幕式结构：**

| 幕 | 占比 | 内容 | 字数 |
|-|-|-|-|

| 第三幕：解决 | 15% | 最终决策→结局 | 100-150字 |



**写作的核心原则：不是写「事实」，是写「角色相信的版本」。**

### 三）流程与机制的选配



#### **1.选机制牌——54张牌里挑4张**



核心思路：机制是为教学目标服务的，不是为了"好玩"加进去的。

剧本杀光有角色和线索还不够，还需要配套的游戏机制来驱动整个流程。54张机制灵感牌分四类：

- ♠ 冲突行动牌（让人对抗、竞争、施压）
- ♥ 社交人性牌（让人信任、背叛、联盟）
- ♣ 逻辑谜题牌（让人推理、验证、排除）
- ♦ 经济成长牌（让人交易、积累、权衡）



查看： [54张机制灵感牌](http://106.53.57.214/T0_54%E5%BC%A0%E6%9C%BA%E5%88%B6%E7%81%B5%E6%84%9F%E7%89%8C.html)

![图片展示了 addCriterion addCriterion图片展示了54张机制灵感牌中的黑桃部分，共13张。每张牌上标有数字和花色，如A、2、3等，部分牌还标注了“冲突”“行动”等标签。图片与上下文紧密相关，上下文提到54张机制灵感牌分四类，此图直观呈现了黑桃冲突与行动类牌，为选牌提供参考，选牌原则是四种花色都要用，不能全选同一类。](https://feishu.cn/file/BRTIbZ0u0ozx35x8Uf5cyR6mn1b)



**选牌的原则：四种花色都要用，不能全选同一类。**

因为一节好课需要平衡四种学习体验：

- 冲突行动 → 让学员感受到"压力"
- 社交人性 → 让学员感受到"关系"
- 逻辑谜题 → 让学员感受到"证据"
- 经济成长 → 让学员感受到"代价"



**我的课选了这4张：**

| 机制牌 | 效果与理由 |
|-|-|
| ♠「最后通牒」 | 某个时间节点后，选项会被锁定，无法再谈判。逼着学员在压力下做决策。 |
| ♥「秘密联盟」 | 两个角色可以私下结盟，共享一条线索。模拟真实职场中的"小团体"现象。 |
| ♣「时间线重构」 | 学员需要把一组邮件按时间顺序排列，推断事件的先后。跟课程知识点"时间管理"直接挂钩。 |
| ♦「资源竞拍」 | 每个角色有一定的"影响力点数"，可以用来竞拍关键线索。让学员体验"资源有限"的真实管理困境。 |



> **💡 选机制的原则** ：先确认主流程类型，再按四种花色各选1-2张。选完之后问自己——"为什么选这张？它服务于哪个教学目标？"

#### 2.写DM手册——培训师的操作说明书



**核心思路：DM手册是给培训师的"安全网"，有了这本手册，哪怕第一次带场也不会慌。**

DM就是主持人，是整场剧本杀的总导演。DM手册有四个板块：



**1)开场话术（三段式）**

> 第一段（30秒）：情境代入 "各位，欢迎来到《最后48小时》。你们是这家公司最后的希望。48小时后，要么公司活下去，你们全员留下；要么，你们每个人都要做出选择。"

> 第二段（1分钟）：规则底线 "游戏过程中，有几条规则你们必须遵守：一，每个角色的信息只属于你自己，不准透露给其他人；二，私聊时间结束后，所有信息必须公开陈述；三，主持人在游戏过程中不会介入你们的决策，但会在关键节点给你们提示。"

> 第三段（10秒）：悬念钩子 "在正式开始之前，我想问你们一个问题——如果你们现在就知道自己会被裁员，你们会怎么做？"



**2)流程控制（时间表）**

| 环节 | 时长 | 核心活动 | 过渡语 |
|-|-|-|-|
| 破冰 | 15分钟 | 规则说明+角色分配+入戏引导 | "现在，请各位写下你们在游戏中的目标" |
| 第一轮 | 40分钟 | 信息释放+公开陈述+首轮决策 | "第一轮结束，你们拿到了一些信息，现在轮到你们做选择了" |
| 私聊 | 30分钟 | 自由谈判+联盟形成 | "私聊时间还剩10分钟，之后你们需要公开你们的决定" |
| 第二轮 | 40分钟 | 信息交换+二轮决策 | "第二轮开始，你们的心态发生了什么变化？" |
| 最终抉择 | 20分钟 | 结果揭晓+复盘 | "现在，我们来揭晓最后的结局" |



**3)干预指南**

| 情况 | 信号 | 标准问句 |
|-|-|-|
| 沉默 | 所有人都不说话，超过1分钟 | "有人想说点什么吗？哪怕你觉得自己的信息不重要" |
| 争吵 | 两个人开始人身攻击 | "停。我们回到问题本身——你们各自的底线是什么？" |
| 偏离 | 开始聊跟游戏无关的事 | "各位，时间在流逝。公司的问题还在那里" |
| 违规 | 有人透露了不该透露的信息 | "等等，这个信息是你角色卡里的吗？" |



**4)应急预案**

- **冷场：** 抛出预设的"剧情炸弹"（如CEO突然发来一条消息）
- **超时：** 压缩复盘时间，保留核心知识点映射
- **争议：** 暂时搁置争议，宣布"游戏继续，争议存档"



**5)使用AI生成DM手册：**

**工具：ChatGPT / Kimi / DeepSeek**

**提示词：**

```Plaintext
请帮我写一份DM手册（主持人手册），包含以下四个板块：

1. 开场话术（三段式：情境代入30秒+规则底线1分钟+悬念钩子10秒）
2. 流程控制（时间表+过渡语+弹性范围）
3. 干预指南（信号识别+标准问句库：沉默/争吵/偏离/违规）
4. 应急预案（冷场/超时/争议/脱离剧本应对方案）

场景背景：
一家创业公司资金链断裂，CEO在48小时内做出决策。4个部门负责人各有立场，最终需要达成"让公司活下去"的共识。

角色清单：
- 刘洋：运营部负责人，D型人格，追求速度
- 王浩：财务部负责人，C型人格，追求精准
- 李娜：市场部负责人，I型人格，追求人心
- 张姐：HR负责人，S型人格，追求稳定

教学目标：让学员理解DISC四种人格类型的决策差异，在压力下做出有效决策。
```



**工具** ： [T7 DM手册模板](http://106.53.57.214/T7_DM%E6%89%8B%E5%86%8C%E6%A0%87%E5%87%86%E6%A8%A1%E6%9D%BF.html)



> 💡 DM手册不是背台词，是给培训师一个"安全网"：有了这本手册，哪怕第一次带场，也不会慌。

3. 重新调整了那个"信息太弱"角色的剧本，加了一条隐藏线索



**第二轮测试（真实场景）：**

在一次培训课上正式跑了一次。

40个学员，分成8组，同时跑。

- 平均完课率比纯讲授版本高出40%

## 六、踩过的坑



**坑一：AI出的初稿不能直接用。** AI写的剧本语言太干，缺乏情感，缺乏偏见——你需要加上角色的情绪、偏见、主观判断，才叫"角色"，不然就是上帝视角。



**坑二：以为做出来就能上线。** 必须先内部测试，找同事/朋友模拟走一遍，记录哪里卡住了、超时了、玩家困惑了，再迭代。



**坑三：工具太多反而效率低。** 不是越多越好，选自己用得顺的，把一个工具用透比同时用5个工具强。



**避坑清单：**

- AI出初稿，人工赋予灵魂——工具是起点，不是终点
- 先内部测试，再正式交付——迭代比完美更重要
- 工具不贪多，用透一个比用5个强

2025年初，一个朋友拉我进了AI破局俱乐部的群。说实话，那时候我对AI还有点抵触——总觉得这东西是割韭菜的。但看着群里天天有人晒用AI做出来的东西，我实在忍不住了。



**历史的长镜头拉远，你会发现，每一个时代都有自己的"破局点"。** 20年前，有人靠互联网翻身；10年前，有人靠移动互联网翻身；今天，AI就是那个破局点。



**但历史同样告诉我们：机会永远只留给那些愿意先动手的人。** 你现在在哪里不重要，你欠了多少钱不重要，你干了多少年也不重要。 **重要的是：你愿不愿意现在就开始？**



**挑一个，压上去，跑通它再说。**



> **把课程变成游戏，让学习变成探险。**
