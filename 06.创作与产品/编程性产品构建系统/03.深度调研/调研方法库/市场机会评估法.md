# 市场机会评估法

> 用来判断一个市场值不值得进入。

---

## TAM-SAM-SOM 模型

| 层级 | 含义 | 估算方法 |
|------|------|---------|
| **TAM**（总可寻址市场） | 理论上所有可能需要这个产品的人 | 行业报告 × 用户基数 |
| **SAM**（可服务市场） | 你的产品能力范围内能触达的人 | TAM × 地理/语言/渠道限制 |
| **SOM**（可获取市场） | 起步阶段实际能拿到的用户 | SAM × 你的渠道能力 × 竞品份额 |

---

## 市场吸引力评估

| 维度 | 问题 | 评分(1-10) |
|------|------|-----------|
| 市场规模 | 市场够大吗？（太小养不活，太大打不过） | |
| 增长趋势 | 市场在增长还是萎缩？ | |
| 付费意愿 | 用户习惯付费吗？还是习惯了免费？ | |
| 进入门槛 | 技术/资金/资质门槛高吗？ | |
| 竞争强度 | 是蓝海还是红海？ | |
| 频次 | 用户多久用一次？（日/周/月/年） | |
| 传播性 | 用户会主动推荐给朋友吗？ | |

---

## 「好市场」的特征

- 市场规模适中：不大不小，大厂看不上，小团队能吃饱
- 处于增长期：用户量在涨，而不是在萎缩
- 用户有付费习惯：最好已经在为类似的东西花钱
- 有自然传播：产品体验好，用户会主动安利
- 离钱近：解决的问题离收入很近，用户更容易买单

---

## 快速判断法（5分钟版）

不用做完整调研，先快速过一遍：

1. 你能找到 10 个「一定会用」的真实用户吗？→ 找不到就先别做
2. 有没有类似的竞品活着而且活得不错？→ 如果有，说明市场存在
3. 这个市场 3 年后还会存在吗？→ 如果会，值得深入研究
4. 你做这件事有独特优势吗？→ 如果没有，想清楚凭什么赢
