# 发布文案模板

> 产品发布时用的文案框架。不同渠道用不同风格。

---

## 通用模板

```markdown
# [产品名] 上线了 🚀

## 一句话
[一句话说清楚产品做什么、给谁用]

## 为什么做这个？
[讲你做这个产品的背景和初衷，让读者产生共鸣]

## 能解决什么？
- 痛点1：
- 痛点2：
- 痛点3：

## 和别的有什么不一样？
[差异化卖点]

## 现在能用吗？
[链接、二维码、如何开始]

## 我需要你的反馈
[引导用户给反馈]
```

---

## 渠道适配

### 即刻 / 推特（短文案）
```
[一句话钩子]
[核心功能，2-3个bullet]
[差异化]
[链接]
#标签1 #标签2
```

### 公众号（长文）
```
[开头：故事/场景引入]
[中间：产品介绍 + 使用场景 + 截图]
[结尾：引导关注/试用/反馈]
```

### 产品猎人 / V2EX
```
标题：[产品名] - [一句话描述]

[做了什么]
[为什么做]
[核心功能]
[技术栈]（如果目标读者是技术人）
[链接]

欢迎试用和反馈！
```

---

## 发布文案 Checklist

- [ ] 一句话能说清楚产品是干什么的
- [ ] 有具体的场景/故事让人产生共鸣
- [ ] 差异化卖点清晰
- [ ] 有明确的 CTA（下一步做什么）
- [ ] 有截图或演示（图文并茂比纯文字好 10 倍）
- [ ] 标签合理
