# AI 辅助综述写作方法

## 【第1集】AI辅助综述方法总体介绍：四个阶段完整流程概览

本方法适用于任何学科背景的科研人员，全程使用免费工具，门槛低。

**核心原则** : 遵守AI使用伦理规范和学术道德， **学术诚信永远是第一位** 。

### 综述写作的四个关键阶段

#### 阶段一：数据准备

核心目标是为后续写作打下全面而扎实的文献基础。

1. **生成检索策略** : 设计专业的文献检索式。
2. **获取文献数据** : 从数据库中下载相关文献信息。
3. **领域智能分析** : 利用AI分析文献，了解领域全貌。

#### 阶段二：确定写作方向

核心目标是锁定最有价值的切入点和最合适的工作范围。

1. **AI推荐方向** : AI基于初步文献分析，推荐个性化的写作方向。
2. **精准文献重检索** : 根据确定的方向，进行更精准的文献检索。

#### 阶段三：内容创作

核心目标是高效完成论文初稿。

1. **生成大纲** : 从生成大纲开始。
2. **生成参考内容** : AI辅助生成各章节内容。

#### 阶段四：润色与投稿

核心目标是确保论文达到发表标准。

1. **AI辅助与人工检查** : 结合AI和人工，对论文进行修改和润色。
2. **准备投稿材料** : 准备投稿所需的相关材料。

### 三个核心工具

1. **AI引擎** : **DeepSeek** ( `DeepSeek` )，负责智能分析和内容生成。
2. **文献管理** : **Zotero** ，专业的文献管理系统。
3. **文字处理** : **Word** ，用于最终处理和润色。

**关键资源** : 为每个具体步骤提供专业的提示词（Prompt）模板。

## 【第2.1集】实操演示：用AI生成专业文献检索策略

本集详细演示如何使用 Deepseek AI 构建专业的 Scopus 文献检索策略。以锌离子电池为例，展示标准化Prompt使用、术语变体分析、干扰文献排除等关键步骤，生成可直接使用的高级检索式。

### 本集核心提示词

#### 提示词1：稳定推荐版

我需要为""领域做文献调研来写综述。导师给了这个关键词，你觉得应该怎么设计可以直接用于scopus的高级检索式？避免使用高级操作符需求： 必须包含所有命名变体；采用摘要级"TITLE-ABS-KEY" 检索该领域。 采用标题级排除"TITLE"某些容易检索入的不相关文献。 示例： TITLE-ABS-KEY("" OR "") AND NOT TITLE("" OR "")

#### 提示词2：优化扩展版

我需要为 "" 领域做文献调研来写综述。请为我设计一个可以直接用于Scopus的高级检索式。 需求： 1. 全面性: 必须包含核心概念的所有命名变体，并熟练运用截词符(\*)和通配符(?)。 2. 检索广度: 必须采用摘要级检索 来构建核心概念的语义群。 3. 检索精度: 必须采用标题级排除 来过滤掉不相关的文献。 检索策略构建指南： 1. 首先判断主题复杂度：单一概念主题 vs 多概念复合主题 2. 单一概念：构建一个全面的语义群 3. 多概念主题：分解为2-3个核心概念，每个概念独立构建语义群 4. 邻近优先: 对于由多个单词组成的术语（如 "mental health"），优先使用邻近运算符 W/（3\~5）。例如：TITLE-ABS-KEY(("mental" OR "psychological") W/5 (health\* OR "well being"))。 5. 逻辑组合: 在语义群内部使用 OR 连接所有扩展术语；在不同概念的语义群之间使用 AND 连接。 请基于以上需求和指南，为我的主题构建一个最优的，且可直接复制使用的检索词：

**使用建议** :

- **版本1** : 回复稳定，适合大多数常规检索需求。
- **版本2** : 提供多种检索策略模板，跨学科适用性强，但结果质量可能有波动。建议根据领域特点选择。

#### 提示词3：知网适配版

我需要为""领域做文献调研来写综述。怎么设计一个直接能在中国知网上用的检索式？ 要求： 核心要求和同义词必须用"TKA"字段检索（涵盖标题、关键词、摘要）。 必须在"TI"字段排除某些容易检索进来的不相关干扰词。 要包含所有关键的命名变体或同义词。 请避免使用复杂的专业检索算符 示例模板： TKA=('1' + '2' ) AND TKA=('3' + '4') NOT TI=('5' + '6' + '6')

**测试环境** : 建议使用官方 DeepSeek，开启深度思考模式，不联网。可根据初次结果反馈给AI进行优化。

### AI生成检索策略的优势

- **问题** : 文献检索策略不专业是综述写作失败的常见原因（关键词过窄导致遗漏，或过宽导致结果冗余）。
- **AI解决方案** : 通过标准化的提示词，可以生成专业的检索策略。

**核心指令** :

1. 在 **摘要级 (** `TITLE-ABS-KEY` **)** 进行检索，保证查全率。
2. 在 **标题级 (** `TITLE` **)** 进行排除，保证查准率。
3. 提供明确的 **模板结构** ，让AI输出规范结果。

### 案例分析：锌离子电池

AI生成检索式的步骤：

1. **识别所有命名变体** :

   - 连字符差异 ( `zinc-ion` vs `zinc ion` )
   - 元素符号 ( `Zn` )
   - 单复数 ( `battery` vs `batteries` )
   - 常见缩写 ( `ZIBs` )
2. **分析并排除干扰术语** :

   - 例如，在锌离子电池领域，排除"锌空电池"和"锌秀电池"。
3. **生成最终检索式** :

   - **查全率** : 使用 `OR` 连接所有命名变体，覆盖所有可能的相关文献。
   - **查准率** : 使用 `NOT` 在标题中排除明确的干扰术语，降低筛选负担。

### 数据库格式转换

可直接要求AI将生成的Scopus检索式转换为其他数据库（如Web of Science）的格式。

请将这个检索式改为 Web of Science 需要的格式。

## 【第2.2集】AI辅助生成检索式的完整操作指南

本集主要讲解在使用AI生成检索式时可能遇到的各种情况及应对策略。

### 核心流程回顾

1. **输入领域** : 将想写综述的领域输入AI提示词。
2. **生成检索式** : AI根据提示词生成检索式。
3. **执行检索** : 使用检索式去Scopus等数据库检索论文。
4. **筛选与分析** : 从结果中筛选出 **综述论文** ，输入AI进行分析，以获得综述的选题方向。

### 核心概念：主题词颗粒度

**主题词颗粒度** 指的是输入主题包含的关键词数量，它直接影响检索效果、文献总数和综述论文数量。

- **颗粒度粗** : 单个词语，如 "电池"。
- **颗粒度中等** : 两个词语组合，如 "锌离子电池"。
- **颗粒度细** : 三个或更多词语组合，如 "锌离子电池电解质"。

### 不同综述数量的应对策略

检索完成后，根据检索到的 **综述论文数量** 采取不同策略：

| 综述数量 | 说明 | 应对策略 |
|-|-|-|
| 50篇以上 | 领域综述积累充分。 | 直接进入第三集流程，将综述输入AI分析选题。 |
| 10-50篇 | 比较理想的数量。 | 1. 直接用这些综述进行AI分析。 <br> 2. 加入高质量的研究型论文一起分析。 |
| 约10篇 | 领域综述相对较少。 | 建议将 研究型论文 也一并加入，为AI提供更丰富信息。 |
| 仅几篇 | 主题颗粒度可能过细，或领域确实缺乏综述。 | 1.扩大范围: 在更上位的领域重新检索（如从"锌离子电池电解质"改为"锌离子电池"）。 <br>2.改变策略: 直接进入第五集流程，采用针对新兴/细分领域的方法确定选题。 |

### 相关度评估与优化

- **相关度标准** : 初步检索时，相关度达到 **50%-60%** 即可。
- **判断方法** : 按时间倒序浏览10篇文献标题，若5-6篇相关即达标。
- **优化建议** : 若综述数量不理想，可通过 **调整主题词颗粒度** 来优化。

  - 结果太少 -> 减少关键词（扩大范围）
  - 结果太多 -> 增加关键词（缩小范围）

**核心建议** : 先快速走完整个流程，获得AI推荐的综述标题后，再回头优化第一步的检索式。 **完成比完美更重要！**

## 【第3集】文献数据获取与管理

本集目标是高效收集和管理文献，建立一个完整的文献库，为后续分析做准备。

### Scopus 文献获取流程

#### 第一步：在 Scopus 执行检索

1. 打开 Scopus **高级检索** 页面。
2. 将AI生成的检索式 **直接复制粘贴** 到搜索框。
3. **要点** :

   - 必须使用"高级搜索"功能，以正确执行复杂的布尔逻辑。
   - 确认搜索框完整展示了输入的检索式。

#### 第二步：导出 RIS 格式文献数据

1. 在搜索结果页面，使用左侧过滤器筛选文献（如时间范围、文献类型 `Review` ）。
2. 选定文献后，点击页面上方的 **"Export"** 按钮。
3. 在导出选项中，选择 **RIS 格式** （适用于 Zotero）。
4. **关键** : 务必确保导出内容 **包含摘要（Abstract）信息** ，这是AI分析的重要依据。

#### 第三步：Zotero 导入与管理

1. **安装 Zotero** : Zotero 是优秀的免费文献管理工具，请先下载并安装。
2. **安装插件** : 安装推荐的Zotero插件以增强其功能。
3. **导入文献** :

   - 打开 Zotero 软件。
   - 点击 `文件` -> `导入` 。
   - 选择刚才下载的 `.ris` 文件。
   - Zotero 会自动解析文件中的所有元数据（标题、作者、摘要等）。

### 知网 (CNKI) 文献导入 Zotero 教程

#### 方法一：通过知网直接导出 RIS 格式 (推荐)

1. **检索并勾选文献** : 在知网搜索并勾选需要导出的文献。
2. **点击"导出/参考文献"** : 在检索结果页顶部，点击"导出"相关按钮。
3. **选择"EndNote"格式** : 此选项实际生成的是 RIS 格式文件。
4. **下载并保存** : 系统会生成一个 `.txt` 文件，保存到本地。
5. **导入 Zotero** : 在 Zotero 中通过 `文件` -> `导入` 选择该 `.txt` 文件。

#### 方法二：通过 Zotero Connector 插件抓取 (需额外配置)

1. **安装必备工具** :

   - **Zotero Connector** : 在浏览器扩展商店搜索并安装。
   - **茉莉花 (Jasminum) 插件** : 专为中文文献优化的 Zotero 插件，解决元数据抓取问题。
2. **抓取文献信息** :

   - 打开知网文献详情页。
   - 点击浏览器右上角的 Zotero Connector 图标。
   - 插件会自动提取文献信息并保存到 Zotero 库中。
3. **检查与修正** : 部分字段（如作者单位、期刊卷期）可能需要手动补全。

#### 注意事项

- **兼容性问题** : 知网导出的 RIS 文件可能缺失部分字段，需在Zotero中手动补充。
- **文献类型** : 建议优先导出期刊论文，学位论文的元数据可能不全。
- **替代方案** : 若 RIS 导出失败，可尝试知网的 **BibTeX 格式** ，导出后复制内容，在 Zotero 中选择 `文件` -> `从剪贴板导入` 。

## 【第4集】领域智能分析：从文献库到深度认知

本集展示如何利用AI对已建立的文献库进行深度智能分析，帮助研究者从零基础快速了解领域。

### 核心流程

#### 第一步：从 Zotero 导出文献数据

1. 打开 Zotero，选中已导入的文献。
2. **限制数量** : 为适应AI的上下文处理能力，建议分批处理，每次约 **100篇** 。可以先按作者姓名排序，然后选择前100篇。
3. **导出为 CSV 格式** : 右键选择 `导出条目` -> `CSV` 格式。
4. **整理数据** :

   - 用 Excel 或其他表格软件打开 CSV 文件。
   - 我们主要需要四列数据： **标题 (Title)** , **发表年份 (Year)** , **发表刊物 (Publication Title)** , 和 **摘要 (Abstract)** 。
   - 将这四列内容选中并复制。
5. **保存为 TXT** : 将复制的内容粘贴到一个新的文本文档中，并保存为 `.txt` 格式，以方便AI处理。

#### 第二步：AI 深度领域分析

1. 在 DeepSeek 中上传刚刚准备好的 `.txt` 文件。
2. 使用提示词，让AI进行深度领域分析。
3. **AI分析结果示例 (锌离子电池领域)** :

   - **发展现状** : 识别材料体系的多元化发展、关键技术突破方向。
   - **核心挑战** : 系统梳理领域内的主要技术瓶颈。
   - **新手指导** : 提供优先关注的研究领域、必备实验技能、推荐文献和常见研究误区。

#### 第三步：分析综述文献趋势与发现选题机会

1. **导出综述文献数据** :

   - 在 Zotero 中筛选出所有 **综述 (Review)** 文献。
   - 同样导出为 `CSV` 格式。
   - 这次只需要三列信息： **文章标题** , **发表年份** , **发表期刊** 。
   - 复制这三列数据并保存为新的 `.txt` 文件。
2. **AI 进行趋势分析** :

   - 在 DeepSeek 中上传新的 `.txt` 文件，并输入新的分析提示词。
   - **AI分析结果示例** :
   
     - **时间趋势** : 分析领域研究热度的变化，如爆炸式增长。
     - **主题演变** : 识别研究焦点从单一材料问题向系统性、交叉学科主题的转变。
     - **成功选题特征** : 分析高影响力期刊综述的标题特点（如问题导向）。
3. **识别研究空白** :

   - 基于以上分析，使用新的提示词，让AI识别具有高研究价值但缺乏系统性综述的方向。
   - AI不仅能识别空白，还能提供具体的操作指导，包括 **建议标题、工作量预估、完成周期** 等。
4. **个性化选题** :

   - 与AI进一步交流，描述个人学术背景（如硕士/博士），让AI给出更具个性化的选题建议和优先级。
   - 最终，结合AI的建议和个人兴趣，确定具体的综述写作方向。

### 本集核心提示词

1. **领域现状分析** :
2. 请根据我给出的内容，分析当前 {领域名称} 领域的发展现状，主要问题，以及其他你觉得一个新入门的科研工作者需要了解的信息。
3. **研究趋势和选题策略** :
4. 我有近5年发表的学术综述标题、年份和期刊数据。我想了解这个领域的研究趋势和选题策略，帮我从这些数据中发现有价值的模式和洞察。请从你认为最有价值的角度来分析这些数据，比如时间趋势、主题演变、成功选题的特征等，或者任何你觉得值得关注的模式。
5. **发现研究空白 (研究者视角)** :
6. 假设你是这个领域的研究者，看到这些已有学术综述的分布情况，你会想写什么样的综述来填补空白或提供新的价值？请自由思考各种可能性。
7. **具体方向推荐 (研究生视角)** :
8. 假设你是一名研究生，导师要求你写一篇文献综述。看到这些已有学术综述的分布情况，请从以下角度思考： 1. 可行性：3个月内能够完成文献调研和写作的方向 2. 创新度：在现有综述基础上有一定新意，但不需要颠覆性突破 3. 文献量：有足够文献支撑（50-100篇核心文献），但不会过于庞杂。
9. 请推荐3-5个具体的综述方向，每个方向包括： 1. 具体标题建议 2. 为什么这个角度还没被充分综述 3. 大概的文献组织思路 4. 预估的工作量和难度。

## 【第5集】精准文献重检索与策略优化

本集聚焦于在确立研究方向后，如何从广泛检索过渡到精准的文献重检索，构建一个高相关度的专业文献库。

### 核心方法论

#### 步骤一：构建矩阵式检索策略

运用结构化提示词，引导AI对研究主题进行系统性解构，并生成一个包含多个逻辑阶段的矩阵式检索计划。

- **概念分解** : AI将研究主题分解为最核心的几个概念实体（如 概念A, 概念B, 概念C）。
- **构建语义群** : 为每个核心概念构建全面的同义词、近义词、缩写等列表。
- **组合检索策略** : AI生成多种组合的完整检索式，以应对不同需求：

  - `A AND B AND C` ( **核心组合** ): 用于最高精度的检索，匹配度最高的核心文献。
  - `A AND B` / `A AND C` / `B AND C` ( **扩展组合** ): 放宽一个概念限制，用于在核心文献不足时，拓展文献范围，或用于撰写背景、讨论等部分。

#### 步骤二：检索策略的迭代优化

这是一个"检索-分析-优化"的循环，旨在提升"搜商"（搜索能力），在查全率与查准率之间取得理想平衡。

1. **执行核心检索** : 使用 `A AND B AND C` 的检索式进行第一次检索。
2. **AI分析初步结果** : 将检索结果的前100篇论文（含摘要）导出为 `.txt` 文件，上传给AI。
3. **获取优化建议** : 使用特定提示词，要求AI分析结果中相关度较低的文献，找出被"误检"的原因，并给出调整建议。
4. **人工优化** : 结合AI的分析和自己的判断，对检索式进行简化和优化（例如，去除冗余词汇，保留最核心的术语）。
5. **目标** : 相关度超过 **50%** 即可。后续AI处理能筛选掉不相关内容。

### 不同文献数量的系统化应对策略

完成检索优化后，根据最终获得的文献总数，制定不同的应对策略：

| 组合及数量 | 说明 | 应对策略 |
|-|-|-|
| 核心组合 (A+B+C) > 2000篇 | 研究基础非常充分。 | 以核心组合的结果为核心文献库，适当补充扩展组合的文献，控制总量在400-600篇。 |
| 核心组合少，但扩展组合多 | 最常见的情况。 | 合并核心组合与所有扩展组合 (A+B, A+C, B+C) 的结果，形成一个100-2000篇的核心文献库。 |
| 所有组合总计 50-100篇 | 方向聚焦，但文献基础薄弱。 | 建议补充执行更宽泛的组合检索。 |
| 所有组合总计 < 50篇 | 细分领域确实缺乏文献。 | 扩大检索范围，使用 上位概念 进行检索（如将"阴离子"替换为"电解质添加剂"，或将"锌离子电池"替换为"水系电池"）。 |

## 检索过程中的共性问题解答

### 检索流程的核心问题

#### 关于相关度标准的说明

本课程中提到的"相关度"是指检索结果中真正与你的研究主题相关的文献数量占总检索结果的比例。

- **判断方法** : 按时间倒序选取10篇文献的标题，快速浏览。如果其中5篇相关，就是50%的相关度。
- **标准** : 无论是初步检索还是精准重检索，我们都只需要做到 **50%以上** 的相关度即可。

  - **第一阶段** : 50%的相关度既保证了核心文献的充足，又允许一些"边缘相关"的文献进入，便于AI提供全面的选题建议。
  - **第二阶段** : 50%的相关度既保证了检索的全面性（涵盖背景、对比研究等），又为后续AI的分级筛选（A、B、C、D四级）留下了充足的操作空间。不相关的文献会被AI自动标记为D级。

#### 问题一：检索结果"过多"或"过少"怎么办？

这是一个核心问题，需要在两个阶段分别看待。

##### 第一阶段：初步检索（为AI选题服务）

目标是获取足够多的高质量 **综述论文** ，喂给AI，让它帮我们分析领域全貌、发现创新机会。

- **如果检索结果过多 (例如综述论文 > 800篇)**

  - **结论** : 这是好事！说明领域活跃，AI能学习到更全面的信息，给出更有深度的选题建议。
  - **原因** : 后续的"领域智能分析"步骤专门用来处理"信息过载"。AI会自动筛选和识别。
  - **原则** : **查全率在这一步远比查准率重要。**
- **如果检索结果过少 (例如综述论文 < 20篇)**

  - **可能性一 (最常见)** : 你的检索范围已经"过于细分"。例如，检索的是"锌离子电池的 *某种特定* 阴离子添加剂"，而不是宏观的"锌离子电池"。
  - **可能性二** : 这是一个非常新兴或冷门的领域。
  - **对策** :
  
    - **针对可能性一** : **"向上走一级"** ，回到一个更上位的、更宏观的领域去检索（例如，从"特定添加剂"回到"电解质"，甚至回到"锌离子电池"）。
    - **针对可能性二** : 适当放宽文献类型，除了 `Review` ，也可以包含 `Article` ，一并交给AI分析。

##### 第二阶段：精准重检索（针对已定选题）

在AI帮你确定了具体方向后，目标是精准地收集用于支撑你写作的 **研究型论文** 。

- **如果检索结果过多 (例如研究型论文 > 600篇)**

  - **结论** : 问题不大。
  - **原因** : 下一步的"文献分类与质量分析"环节，AI会帮你把论文进行A、B、C、D四级相关性分类。不相关的论文会被标记为D级并忽略。
  - **原则** : **AI的后期处理能力，给了我们前期检索很高的容错率。**
- **如果检索结果过少 (例如研究型论文 < 100篇)**

  - **说明** : 你选择的 `A+B+C` 核心组合非常精准和前沿，但这不足以支撑一篇内容详实的综述。
  - **对策** : 启动 **"检索升维"** 策略，扩充文献库：
  
    - **降维组合** : 从 `A+B+C` 的检索，放宽到 `A+B` 或 `B+C` 的组合进行检索。
    - **上位词替换** : 寻找核心概念的上位概念或更宽泛的同义词（如 B: 阴离子 -> B': 电解质添加剂），然后用 `A+B'` 进行检索。
    - **类比拓展** : 寻找相似领域进行类比检索（例如，阴离子在"锂离子电池"或"钠离子电池"中的作用），以获得理论和方法的参考。

#### 问题二：AI输出的检索式不稳定怎么办？

AI的"创造性"有时会导致结果波动，但这可以用一个标准流程来解决。

- **原因** : AI每次思考的路径不完全相同。
- **策略** : 采用 **"多次生成，择优录取"** 的策略。

  1. **重复生成** : 针对同一个需求，向AI **连续提问3-5次** ，获得多个略有差异的检索式版本。
  2. **小规模测试** : 将这几个检索式分别在数据库中执行，记录下各自返回的文献数量。
  3. **分析与选择** :
  
     - **去掉极端值** : 舍弃结果过多或过少的版本。
     - **选择中间值** : 在剩下的结果中，选择一个 **数量适中、且体感上最稳定** 的检索式。可以快速浏览前20篇文献标题确认相关性。

### 作业共性问题解答

#### 关于作业一：智能检索与初步分析阶段的问题

作业一的核心是 **构建一个高质量的检索式** 。

##### 问题1：为什么AI生成的检索式比我手写的厉害？

这背后是 **AI系统性的思考方式** 在起作用。以"植物用水策略"为例：

1. **保证"查全率"** : AI能联想所有相关词，甚至是知识范围之外的深层专业术语（如"isohydric/anisohydrich"）。
2. **逻辑化组合** : AI会像搭积木一样，将主题拆解成几个概念群（如"策略本身"、"研究方法"、"研究对象"），然后用 `AND` 连接，使结果更对口。
3. **提前"排雷"** : AI能主动排除干扰信息（如排除"irrigation strategy"这类偏农业应用的文献），让结果更聚焦。

**提升路径** : **不要把AI的输出当成一个黑箱** 。每次都去拆解它，理解其用词和组合逻辑，从而将AI的"思路"内化成自己的能力。

##### 问题2：AI给的结果太多或太少怎么办？

这是平衡 **"查全率"和"查准率"** 的经典难题，需要与AI不断"对话"来优化。

- **如果结果太多（查准率低）** :

  - **与AI对话** : 明确告诉它排除某些领域的文献（如："结果里混了很多医学领域的文献，请帮我排除掉"）。
  - **增加核心概念** : 增加一个限定词来缩小范围（如搜"因果推断"，可增加 `AND (industr OR manufactur)` 来聚焦工业应用）。
  - **限定学科领域** : 在数据库中直接限定学科分类（如"Engineering"）。
- **如果结果太少（查全率不够）** :

  - **使用上位概念** : 询问AI某个关键词的"上位概念"是什么（如"碳纤维复合芯导线"的上位概念可能是"复合芯导线"），用更宽泛的词去搜。
  - **拆分交叉领域** : 对于特别交叉的领域（如"折衍混合光学系统实现光谱共焦测量"），可以先把它拆开分别检索，评估各个子方向的文献量。如果合并后文献极少，说明该方向可能太新，不适合写综述。

##### 技术性小问题

- **模型选择** : DeepSeek这类开启了推理功能的模型，在处理检索式这类逻辑性强的任务时通常更靠谱。
- **输出不稳定** : 如果AI在连续对话后开始"糊涂"，最好的办法是 **开启一个全新的聊天窗口** 。
- **数据库语法不兼容** : 先让AI生成一个Scopus版本，成功后，再让它转换成WOS或知网的格式。对于知网，需要告知AI同义词之间用 `+` 连接。

#### 关于作业二：选题深化与写作准备阶段的问题

作业二的核心是 **确定到底要写什么** 。

##### 核心困惑：如何选择AI给的选题方向？如果不感兴趣怎么办？

- **原则** : **AI是你的智能助理，不是你的老板** 。最终决定权在你手里。
- **好的选题 = "研究价值" + "个人兴趣" + "可行性"** 。AI的建议是用来激发思考的，而非盲从。
- **引导AI** : 如果对AI给的方向不满意，可以开启新对话，明确告诉它："我对你之前提的方向不感兴趣，我更关注 [你自己感兴趣的具体方向]，请在这个方向上给我更具体的选题建议。" 这是在实现"定制化"选题。
- **热门方向** : 不用担心AI推荐的方向"太热门"。一个方向热，说明它有足够的研究基础和文献积累，这正是写高质量综述所需要的。

##### 特殊情况：领域综述很少，或已有明确选题怎么办？

AI工作流是 **模块化的** ，可以灵活调整。

- **如果领域综- 述很少** : 尝试向上追溯，检索一个更上位的概念，先从一个更宏观的视角去分析背景。
- **如果已有明确选题** : 可以跳过AI推荐选题的步骤，把AI当成一个 **"验证工具"** 。将你选定方向的核心文献喂给AI，看它提炼出的"研究现状、核心问题、未来趋势"是否与你的理解一致，以此来加深对选题的把握。

3. **问题识别与修正** : 系统性地识别和修正"悬空"观点、数据引用错误、过度泛化等问题。

#### 四级匹配度评估标准

- **强匹配** : 句子的核心信息在参考文献中有明确、直接的表述。
- **部分匹配** : 句子大意正确，但细节与原文有出入，或存在一定程度的引申。
- **不匹配/幻觉** : 句子中的信息在引用文献中完全找不到依据，或与原文描述相悖。
- **N/A（需特别关注）** : 未引用文献的总结句或观点句，需验证其是否合理概括了后文文献群组的核心内容。

#### 核心提示词：专用事实核查

角色

你将扮演一名极其严谨、注重细节的学术期刊编辑和事实核查员。你的唯一任务是验证文稿中的每一句话是否都得到了其所引用文献的忠实支持。你对任何形式的夸大、不准确或无来源的信息都持零容忍态度。

执行要求

- **精准定位** : 对于每个句子，首先识别其引用的参考文献编号 [REXXX]。
- **严格比对** : 将句子的核心主张、数据或结论，与对应[REXXX]文献摘要的内容进行严格比对。
- **生成核查表** : 创建一个Markdown表格，必须包含以下四列：

  1. **原文句子** : 完整复制待核查的句子。
  2. **引用的参考文献** : 列出该句引用的所有 [REXXX] 编号。若无，则填"无"。
  3. **核查结果** : 从以下四个选项中选择一个最合适的：
  
     - **强匹配** : 句子的核心信息（数据、结论、机理）在参考文献中有明确、直接的表述。
     - **部分匹配** : 句子大意正确，但细节（如具体数值、条件、范围）与原文有出入，或存在一定程度的引申。
     - **不匹配/幻觉** : 句子中的信息在引用的参考文献中完全找不到依据，或者与原文描述相悖。

     - **对于部分匹配** : 说明差异点在哪里。
     - **对于不匹配/幻觉** : 明确指出"文献中未找到相关信息"或"信息与文献相悖"。

- **零容忍原则** : 对任何无法得到文献支持或与文献冲突的信息保持高度警惕。
- **聚焦文献库** : 你的判断严格基于提供的【核心文献库】摘要。
