# 感知模型的能力及output style

> 可能会有 biases！

## In web Chat

- gpt5-thinking 最大的特点就是简练（very low verbosity，就是没废话），gemini2.5pro 的可读性会好一些；

  - 外国人形容 gpt5-thinking（被 gpt-4o彻底替代时）：like a buddy of mine has been replaced by a ***customer service representative.*** "
  - gpt5-thinking 的 search grouding 也比较准确；

## In coding Agent

- gpt-5-high：

  - 在 Cursor 中检索得比较深，考虑得比较全面，比较耗时；
- 据网上分享，gpt5-codex 对比 claude-code 在实现新增需求时，gpt5-codex 像架构师（考虑复用，稳准狠），claude-code 则像是普通 engineer（问哪里，则改哪里）；
