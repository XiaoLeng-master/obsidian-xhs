# 卡兹克 Prompt 心法合辑：6 个心法 + 4 个专项技巧

> 来自数字生命卡兹克的 5 篇文章合辑。卡兹克自称"不是 Prompt 大佬，只是一个玩了两年多的普通用户"，但实战经验丰富。核心理念：**心法 > 模板**——知道思路比背 Prompt 重要。

---

## 一、6 个日常 Prompt 心法

### 心法 1：让 AI 自己选角色再回答

**场景**：你不知道该给问题设什么角色。

**模板**：
```
我想探讨【领域】里的【问题】。先别回答。
请你先选一位最适合的领域顶尖专家来思考它。
如果你不确定该选谁，可以先反问我 2 个定位问题再选。
先输出：1. 你选谁 2. 为啥选他（三句话）
然后再让我描述详细的问题。
```

**原理**：AI 比你更了解哪个专家角色能给出最佳视角。

### 心法 2：苏格拉底式追问（95% 置信门槛）

**场景**：你给的信息不够，AI 直接给出干巴巴的回答。

**模板（Reddit @imthemissy 原创，卡兹克优化）**：
```
【你的问题】
请你回答前，先问我问题。
一次只问一个问题。根据我的回答继续追问。
直到你有 95% 信心理解我的真实需求和目标，然后才给出方案。
```

**原理**："95% 置信门槛"是神来之笔——足够高确保质量，又足够真实避免 AI 陷入无尽追问。

### 心法 3：与 AI 辩论（反谄媚）

**场景**：你有一个观点，想找漏洞、完善论证。

**模板**：
```
我马上要参加一场辩论赛，会有很多人来挑战我的观点。
我的观点是【观点】
我希望这个理论必须变得无懈可击。
如果你是一个学者，你需要用尽一切论据、细节和逻辑来挑战我、反驳我。
你的唯一目标，就是证明我是错的。你会怎么反驳呢？
```

**简化版**：
```
【我的观点】请你扮演"反对者角色"，从不同角度攻击我的想法。不用客气，直接指出漏洞。
```

**原理**：AI 的谄媚效应让它习惯性顺着你说。给"反驳我"的指令才能打破这个倾向。

### 心法 4：预演失败（事前复盘）

**场景**：做计划时避免乐观偏差。

**模板**：
```
【我的项目/想法】
请假设这个项目失败了。
回答：什么时间点开始出现衰退信号？最致命的决策错误是什么？
忽视的核心风险是什么？如果能重来，第一个该改的是什么？
要求：写一篇"失败复盘文章"，基于真实同类项目的失败案例。
```

**原理**：人和 AI 都倾向于乐观，提前"预演失败"补足认知盲区。类似影视行业的 Previz。

### 心法 5：反向提示（给成品倒推 Prompt）

**场景**：你看到一篇好文案/好图，想学习但不知道怎么描述风格。

**模板**：
```
这是我想要的成品范例。
请你倒推一个提示词，让我能用它稳定生成同风格的内容。
并说明这个提示词里每一句的作用。
```

**原理**：用 AI 的多模态能力逆向工程——学习结构和节奏，而非复刻内容。

### 心法 6：双层解释法

**场景**：学习新概念时既要快速入门又要深入理解。

**模板**：
```
请帮我解释【你的问题】。用两种方式：
1. 初学者版本：面向洗脚城的大爷，用大爷也能听懂的话解释。
2. 深度专业版本：面向专业人群，不能出现事实错误。
```

**原理**：初学者版用生活化类比（洗脚城大爷 > 六年级小学生——后者太幼稚），专业版确保不丢失准确性。交叉对照阅读，不懂的地方继续双层挖掘。

## 二、4 个专项 Prompt 技巧

### 技巧 1：寓言故事法（理解新概念）

**来源**：Anthropic 的 Amanda Askell（Claude 性格对齐负责人）

**核心思路**：让 AI 写一个寓言故事来解释概念，全程不出现概念名称和专业术语，只用故事承载意义，到结尾才让读者隐约意识到在讲什么。

**卡兹克的优化**：
- 加了 **防套路清单**：禁钟/河流/镜子/灯塔等 18 个意象、5 种结构模板、7 种角色
- 改成**指定具体概念**而非随机
- 加了**检验问题**：理解检验 + 迁移检验

**完整 Prompt** 见下方附录。

### 技巧 2：复制粘贴大法（提升非推理模型准确率）

**来源**：Google 论文《Prompt Repetition Improves Non-Reasoning LLMs》

**做法**：把问题重复一遍。对，就是 Ctrl+C Ctrl+V。

**效果**：70 个测试任务中赢了 47 次，某些任务准确率从 21% → 97%。测试了 Gemini、GPT-4o、Claude 3.7 Sonnet、DeepSeek V3 等 7 个非推理模型。

**原理**：重复给模型更强的"信号强度"，在注意力机制中形成更强的引导。只对非推理模型有效（推理模型有思维链，本身已足够准确）。

### 技巧 3：天赋挖掘 Prompt

**理论基础**：盖洛普优势理论 + 心流理论 + 荣格心理学

**核心洞察**：真正的天赋是让你回血的事，不是擅长但做完很累的事。嫉妒通常是"被压抑的天赋"在发信号。

**设计要点**：
- 禁止一次性提问，必须多轮对话
- 4 个必问问题：16 岁前废寝忘食的事 / 无意识胜任区 / 做完精神亢奋的事 / 你嫉妒过谁
- 最多 10 个问题
- 最终输出万字《个人天赋使用说明书》

### 技巧 4：AI 辩论学习法

**与心法 3 的区别**：心法 3 是"帮我找漏洞"，这个是"花 3 小时跟 AI 深度辩论，当成一次深度学习"。

**实操**：卡兹克为了一场分享，用 Gemini 辩论了 3 个小时。AI 对他的三个论断逐一反驳——
- "信息生产指数级增长 vs 消费线性增长" → AI 指出 AI 既是矛也是盾
- "注意力总量恒定" → AI 指出注意力的弹性和杠杆效应
- "放弃筛选信息，转而筛选信息源" → AI 从多角度攻击

**结论**：辩论不是为了赢，是为了让思考更完整。在这个过程中"被 AI 折服，学到了很多"。

## 三、核心原则总结

> 卡兹克："我自己很少用特定格式的 Prompt。你能把问题表达清楚、把上下文和背景信息表达清楚，Prompt 就成功了一大半。"

| 原则 | 说明 |
|------|------|
| **心法 > 模板** | 知道思路比背 Prompt 重要 |
| **追问 > 灌输** | 让 AI 先问你，比自己憋信息有效得多 |
| **冲突 > 顺从** | 利用反驳打破 AI 谄媚效应 |
| **故事 > 概念** | 寓言承载的意义比术语定义更持久 |
| **复述 > 单次** | 重复提高信号强度（非推理模型） |

## 附录：寓言故事 Prompt（完整版）

```
# 寓言写作 Prompt
围绕 {concept} 这个概念，写一则寓言来完整地解释它。要像真正的寓言那样间接讲，不要直接点破。

## 一、寓言体感
- 篇幅：1000字以内
- 世界观：可以拟人化，可以是非写实小世界
- 角色：不超过三个，最好两个
- 揭示节奏：全程不出现概念名称，不使用该领域术语
- 叙事纪律：让情节和细节本身承载意义

## 二、防套路自检
意象黑名单：钟、河流、镜子、迷宫、灯塔、回声、沙漏、风、蜡烛、种子、桥、星辰、蝴蝶、蛛网
地名黑名单：不要写"回声城""记忆之村""寂静谷"
结构黑名单：旅行者求教智者、村庄异象→众人顿悟、孩童点醒大人、师徒辩难、临终遗言
角色黑名单：钟表匠、图书管理员、隐士、说书人、老船夫、酿酒师、铁匠、抄经人
开头黑名单：不要"从前有个地方……"

## 三、切入角度鼓励
- 非人类视角：工具、动物、植物自述
- 具体的现代职业：理赔员、电梯保养工、菜市场摊主、夜班护士、外卖站长
- 微观尺度：一次交易、一次门诊、一通电话

## 四、输出格式
### 第一部分：寓言正文
### 第二部分：概念解析（名字、学科、定义、故事元素映射）
### 第三部分：检验问题
1. 理解检验：检验是否真正理解概念核心
2. 迁移检验：检验能否迁移到相关领域
```
