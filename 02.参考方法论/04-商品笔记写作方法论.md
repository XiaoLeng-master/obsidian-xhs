# 商品笔记写作方法论

> 说人话，给干货，下指令。八个字就够了。商品笔记不是文学创作，是让用户3秒看完就想下单的临门一脚。

---

## 一、商品笔记 vs 推广笔记

这两个东西完全不一样，别搞混：

| 维度 | 商品笔记 | 推广笔记（自然流） |
|------|----------|------------------|
| 有没有挂商品链接 | 有 | 没有 |
| 流量来源 | 商品流量（精准） | 内容流量（泛） |
| 流量大小 | 本身就不大，但转化率高 | 大，但转化路径长 |
| 成功标准 | 点赞超过2就说明流量不差，接近100就是爆单笔记 | 看点赞/收藏/评论 |
| 写法 | 直接、简短、突出卖点 | 内容为王，间接种草 |

---

## 二、写商品笔记的三层境界

1. **抄同行**——找到卖得好的对标，拆他的结构
2. **抄相近行业**——跨品类找灵感
3. **抄自己**——这是最高境界。只有你自己爆过的笔记，你才知道它所有数据的全貌：是不是靠商品流走起来的、转化率高不高、关键点在哪。然后反复抄自己的爆款

## 三、封面设计

封面决定了笔记的生死——用户划过只需要0.5秒。

### 4种封面类型

| 类型 | 特点 | 适合 |
|------|------|------|
| 大字报 | 制作最简单，一行大字搞定 | 所有虚拟产品 |
| 实拍型 | 拍电脑/iPad打开产品页面 | 知识库、电子书 |
| 截图型 | 截取产品中最吸引人的内容 | 资料包、模板 |
| 干货型 | 信息密度极高，一看就想收藏 | 备考资料、知识清单 |

### 封面设计原则
- 竖版3:4（小红书原生比例，展示面积最大）
- 配色不超过3种
- 核心信息占画面60%以上
- 字数不超过20字
- **虚拟产品封面不需要精美设计**——太精致反而像广告

### 封面文案结构（3行）
```
第一行（钩子/痛点）：最大字号
第二行（产品价值）：中等字号
第三行（行动指引）：最小字号
```

## 四、标题写作

### 7个标题技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 巧用关键词 | 利用搜索下拉词组合 | 关键词+场景/人群 |
| 注入情绪 | 用情绪词提升点击率 | "绝了""后悔""救命""亲测" |
| 紧跟热点 | 结合当前热门话题 | 热点事件+你的产品 |
| 借助权威 | 引入名人/专家/数据 | "清华学霸都在用的..." |
| 数字凸显 | 数字+关键词+结果 | "30天搞定XXX的方法" |
| 价值强调 | 突出实用性 | "一份搞定XXX" |
| 对号入座 | 直接指向特定人群 | "给25岁还在迷茫的你" |

### 封面和标题的配合原则
- **封面和标题不要重复**——封面说痛点，标题说解决方案，或反过来
- 形成信息互补，让用户看到封面+标题就有点击欲望

## 五、正文写作

### 核心公式

**痛点场景 + 解决方案 + 价值展示 + 行动指令**

### 3种高转化正文结构

**结构一：痛点+方案型**
```
第1段：痛点场景（你是不是也XXX？）——勾住用户
第2段：解决方案（我找到了一个XXX）——给出路
第3段：产品展示（里面有XXX）——展示价值
第4段：行动指令（点击蓝色链接直接拿）——引导下单
```

**结构二：场景代入+情绪上头型**
```
第1段：具体场景描述（昨晚12点，我又在XXX...）
第2段：转折（直到我发现了XXX）
第3段：使用效果（用了之后XXX的感觉太爽了）
第4段：产品露出+CTA
```
> 这种结构互动率通常更高

**结构三：清单干货型**
```
标题：X个XXX的方法/资料/工具
正文：
1. XXX
2. XXX
3. XXX
...
结尾：完整版在蓝色链接里
```
> 适合收藏型内容，收藏率高

### 正文写作原则
- **前3行决定生死**——用户划走只需0.5秒，开头必须勾人
- **说人话**——像跟朋友聊天，不要书面腔
- **给干货**——让用户觉得"这个人懂"
- **下指令**——明确告诉用户怎么买

## 六、评论区引导

商品笔记的评论区是第二战场：

| 引导方式 | 操作 |
|----------|------|
| 置顶评论 | 自己评论一条，引导用户点击商品链接 |
| 回复评论 | 积极回复每一条评论，增加互动 |
| 引导提问 | 正文末尾用"你们最想看什么？"引发评论 |
| 制造从众 | "已经XXX人拿到了""好评太多了" |

## 七、写商品笔记的完整流程

```
第1步：确认弹药就绪（画像+关键词+模板+情绪）
        ↓
第2步：选封面类型，写封面文案
        ↓
第3步：用7个技巧起标题（至少写3个备选）
        ↓
第4步：选正文结构，写正文（埋关键词+打情绪+CTA）
        ↓
第5步：发布，24小时后看数据
        ↓
第6步：数据好→复制裂变；数据差→换封面换标题重发
```

---

## 八、核心原则

1. **商品笔记的流量比自然流精准得多，所以自然不会很大**——点赞超过2就说明流量不差
2. **先发笔记测流量，有流量了再重点打磨**——不要自嗨
3. **一篇好笔记完爆50篇垃圾笔记**——质量 > 数量
4. **只要你的内容被对的人群看到，而且商品在平台内有需求，你一定会出单**——是一定，不是大概率
5. **核心信念：不比价**——小红书用户不比价，你的内容好，贵一倍用户也从你这里买
