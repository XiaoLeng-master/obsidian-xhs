# 写笔记前的4步弹药准备

> 做小红书最常见的死法：闷头写，写了发，发了没流量。不是不努力，是压根没想清楚就动手了。

---

## 核心理念

写笔记之前，你要搞清楚4件事：

1. **卖给谁？** → 精准客户画像
2. **用什么词被搜到？** → 长尾关键词扩展
3. **参考谁的结构？** → 爆款结构分析
4. **打什么情绪让用户上头？** → 产品情绪洞察

这4步搞定了，爆款的概率大幅提升。一个品跑一次就够，后续写笔记时直接调用。

---

## 第1步：精准客户画像

### 为什么要做

小红书是内容电商、兴趣电商。用户不比价，同样的产品即使贵一倍，只要内容打动她，她就会在你这里买。

所以画像的核心不是"谁会买"，而是**"谁看了你的内容会上头下单"**。

### 怎么做

为你的产品生成3个精准客户画像——不是"想赚钱的人"这种泛人群，而是具体到能"看到一个活生生的人"。

**每个画像要包含：**

| 维度 | 要回答的问题 |
|------|------------|
| 基础信息 | 年龄、职业、收入、城市、婚姻状态 |
| 生活场景 | 她的日常是什么样的？什么时候会产生购买需求？ |
| 痛点需求 | 客观需要什么？主观想象什么？现有竞品没解决什么？ |
| 购买动机 | 什么场景下会下单？决策因素TOP3是什么？ |
| 评论区表达 | 这类人在评论区通常会说什么？（这些就是你的情绪弹药） |

### 关键原则

- **"30岁的女人"不是人群，"女大学生"和"富婆"才是人群**——颗粒度要足够细
- **区分"客观需要"和"主观想象"**——用户买的不是PDF，是"拥有这份资料后想象中更好的自己"
- **3个画像之间要有明显差异**——上班族/宝妈/学生的痛点完全不同

## 第2步：长尾关键词扩展

### 为什么要做

小红书日搜索量7亿次，73%用户每天都在搜索。标题和正文里有没有埋对关键词，直接决定笔记能不能被搜到。

**虚拟产品的搜索词有个特点：** 用户搜的往往不是产品名，而是问题和需求。不会搜"考研英语资料包"，而是搜"考研英语怎么背""考研英语5500词记忆法"。

### 怎么做

从种子关键词出发，扩展为完整的关键词矩阵：

| 词类型 | 说明 | 用在哪 |
|--------|------|--------|
| 下拉词 | 用户实际在搜的词 | 标题、正文 |
| 痛点词 | 用户的问题 | 开头钩子、封面 |
| 方案词 | 用户想要的答案 | 正文、商品详情页 |
| 场景词 | 使用场景 | 内容切入角度 |
| 情绪词 | 带情绪的搜索 | 封面大字、标题 |
| 评论区高频词 | 从爆款评论区提取 | 标题、封面、正文 |

### 关键词优先级

- 高优先（蓝海词）：搜索量大 + 竞争低 + 与产品强相关
- 中优先：搜索量中等 + 竞争中等
- 低优先：可选择性布局

### 关键词使用建议

- **标题必埋词**：从高优先词中选1-2个，直接放标题
- **正文自然植入词**：中优先词分散在正文各段
- **封面大字词**：选1个最抓眼球的痛点词或情绪词
- **商品详情页词**：方案词放进商品描述

## 第3步：爆款结构分析

### 为什么要做

"非必要不原创，借鉴性模仿是最佳性价比。" 找到你赛道里卖得好的对标笔记，拆解它的结构，提取可复用的模板。

### 怎么做

找一篇同品类的爆款笔记（标题+正文+数据），从6个维度拆解：

| 维度 | 拆解内容 |
|------|---------|
| 结构拆解 | 逐段拆解每段的功能、字数、作用 |
| 风格特征 | 语言风格、人称、句式特点、信息密度 |
| 情绪设计 | 情绪曲线（开头→中间→结尾的情绪变化） |
| 人性弱点运用 | 用了哪些人性弱点：懒惰/贪婪/从众/恐惧/虚荣/好奇心/损失厌恶 |
| 转化设计 | CTA在哪、怎么引导下单 |
| 可复用模板 | 标题模板、封面模板、正文模板、替换规则 |

### 关键原则

- **拆的是"骨架"，不是"皮"**——结构是经过验证的，素材要换成自己的
- **区分商品笔记和自然流笔记**——商品笔记走精准流量，自然流走内容流量，结构不同
- **暂时没有对标也没关系**——这步可以跳过，后面找到对标再单独做

## 第4步：产品情绪洞察

### 为什么要做

用户下单从来不是因为"需要"，而是因为"上头"。你要知道你的产品能打什么情绪。

### 6种核心情绪

| 情绪 | 用户心理 | 文案切入方向 |
|------|---------|-------------|
| **恐惧** | 怕落后、怕失败、怕被淘汰 | "还不会XX，你就危险了" |
| **厌恶** | 讨厌现状、受够了某种处境 | "受够了XX？试试这个" |
| **愤怒** | 觉得不公平、被欺骗 | "凭什么XX？因为你缺这个" |
| **悲伤** | 无力、失落、自我怀疑 | "我理解你的XX，但有办法" |
| **惊讶** | 信息差、认知颠覆 | "原来XX竟然可以这样" |
| **喜悦** | 想象使用后的爽感 | "用了之后XX的感觉太爽了" |

### 情绪背后的人性弱点

| 人性弱点 | 对应情绪 | 文案中怎么用 |
|----------|----------|-------------|
| 懒惰 | 喜悦 | "不用动脑，跟着做就行" |
| 贪婪 | 惊讶/喜悦 | "花XX元省了XX万" |
| 从众 | 恐惧 | "XXX人都在用" |
| 恐惧 | 恐惧 | "再不XX就来不及了" |
| 虚荣 | 喜悦 | "同事都来问我怎么做的" |
| 攀比 | 悲伤/愤怒 | "为什么别人能XX你不能" |

### 关键原则

- **不是6种都要用，找最能打的1-2种重点打**
- **情绪组合比单一情绪更有效**——比如"恐惧+喜悦"（先制造焦虑，再给出路）
- **每个情绪要落到具体场景**——不能只写"恐惧"，要写"周一早上被老板骂完回到工位打开手机时的恐惧"

---

## 4步完成后的产出

跑完4步，你会得到一张**弹药库速查卡**：

| 模块 | 内容 |
|------|------|
| 卖给谁 | 主力人群 + 一句话画像 |
| 用什么词 | 高优先关键词TOP10 + 标题词 + 正文词 |
| 参考谁的结构 | 模板名称 + 核心结构公式 |
| 打什么情绪 | 主打情绪 + 辅助情绪 + 情绪句式TOP3 |

后续每次写笔记，打开速查卡直接用，不用每次重新想。
