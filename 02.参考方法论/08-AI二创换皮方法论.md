# AI二创换皮方法论

> AI换皮的核心是知识点不变，改变表达方式、语气和结构。不是简单换词，而是重新组织信息。

---

## 一、什么是AI二创换皮

把买来的或手头现有的虚拟资料，用AI进行深度二创改写，让查重率降为0，变成你自己的原创产品。

**本质：** 保留核心知识点 + 改变表达方式、语气和结构 = 你的原创产品

**不是什么：** 不是"把A换成B"的同义词替换，而是重新组织信息的深度改写。

---

## 二、3套二创策略

根据资料类型选择最适合的策略：

| 资料类型 | 推荐策略 | 适用场景 |
|----------|----------|----------|
| 文字类（通用文档、清单、合集） | 通用降重版 | 大部分场景 |
| 概念/理论/观点类（知识库、专业文章） | 深度扩充版 | 需要增加深度和专业感 |
| 教程/步骤/SOP类（操作指南） | 实操细化版 | 需要更详细的执行步骤 |

---

### 策略一：通用降重版

**适用于大部分文字类资料。** 核心是打散重组+句式变换。

| 改写手法 | 具体操作 |
|----------|----------|
| 结构打散重组 | 严禁照搬原文段落顺序，重新规划信息架构 |
| 句式彻底变换 | 被动句改主动句，长难句拆短句，陈述句改疑问句 |
| 视角切换 | 改为第一人称经验分享视角，像"过来人"在跟你聊 |
| 去AI味 | 模仿真人说话习惯，加口语化表达 |
| 保留核心 | 专有名词、数据、法规条文100%保留 |
| 增加可读性 | 补充过渡句，让段落之间有逻辑衔接 |

### 策略二：深度扩充版

**适用于概念、理论、观点类资料。** 核心是在原有基础上做专业化延伸。

| 步骤 | 操作 |
|------|------|
| 专业化重述 | 用该领域的专业语言重新表达核心观点 |
| 逻辑延伸 | 对每个核心观点补充Why（为什么重要）和How（怎么落地） |
| 案例植入 | 为关键论点补充真实案例或场景化例子 |
| 结构化输出 | 用清晰的层级结构组织（大标题→小标题→要点→解释→案例） |

### 策略三：实操细化版

**适用于教程、步骤、SOP类资料。** 核心是把简略流程变成详细执行指南。

| 改写手法 | 具体操作 |
|----------|----------|
| 细节填充 | 每个步骤补充"在哪里点""点完会看到什么""如果出错怎么办" |
| 精准表达 | 操作类内容要精准，不要模糊表达 |
| 参数量化 | 时间、数量、尺寸等用具体数字表示 |
| Markdown排版 | 用代码块、表格、列表增强可读性 |
| 新手友好 | 假设读者完全零基础，补充前置知识说明 |

---

## 三、混合使用

一份长资料可以对不同章节使用不同策略：
- 理论部分 → 深度扩充版
- 操作部分 → 实操细化版
- 通用内容 → 通用降重版

---

## 四、核心原则

1. **必须人工审核**——AI二创后的内容一定要过一遍，特别是专业术语、数据、案例是否准确
2. **去除旧水印**——原资料中的logo、水印、联系方式必须全部去掉
3. **不要碰机构或大IP**——有明确作者、机构标识的内容不做二创，有版权问题
4. **保留核心价值**——二创的目的是降重+提升体验，不能改到核心知识点都变了
5. **不是简单换词**——"把A换成B"的同义词替换不叫二创，重新组织信息才叫
