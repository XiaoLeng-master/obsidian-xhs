# 多平台敏感词避坑指南

> 一篇笔记写得再好，踩了敏感词就白搭——轻则限流，重则封号。

## 一、8大敏感词分类

### 1. 政治敏感类（最高风险）

直接封号级别。政治人物、敏感事件、分裂国家相关。

**处理方式：** 直接删除，没有替换方案，不要碰。

### 2. 色情低俗类（高风险）

| 违规词 | 替换词 |
|--------|--------|
| 性感 | 有魅力、优雅、有气质 |
| 荷尔蒙 | 心动、吸引力、魅力值 |
| 约会 | 见面、相处、交流 |
| 撩妹/撩汉 | 吸引TA、提升魅力 |

**平台差异：** 小红书对"性感""诱惑"特别敏感；抖音禁止约会交友引导。

### 3. 广告导流类（高风险）

| 违规词 | 替换词 |
|--------|--------|
| 私信我 | 评论区回复/留言 |
| 加微信 | 关注账号获取 |
| 点击链接 | 主页查看更多 |
| 扫码 | 图片查看（仅公众号可用） |

**平台差异：** 小红书严控"私信""留言送"；抖音禁止评论区引导加微信。

### 4. 医疗健康类（高风险）

| 违规词 | 替换词 |
|--------|--------|
| 治愈 | 缓解、改善、帮助 |
| 根治 | 调理、养护、辅助 |
| 医疗级 | 专业级、高标准 |
| 特效 | 显著、明显、有帮助 |

**关键：** 不提疗效，只讲体验。

### 5. 金融诈骗类（高风险）

| 违规词 | 替换词 |
|--------|--------|
| 赚钱 | 增加收入、提升价值 |
| 日入XX | 分享收入经验 |
| 投资理财 | 财务规划、资产管理 |

**平台差异：** 抖音严控"赚钱""收益"；小红书禁止金融产品推广。

### 6. 极限用词类（中风险）

《广告法》禁用词：

| 违规词 | 替换词 |
|--------|--------|
| 最好 | 很好、非常好、优秀 |
| 第一 | 领先、前列、优选 |
| 唯一 | 稀有、少见、独特 |
| 官方推荐 | 值得选择、热门推荐 |

### 7. 引战争议类（中风险）

| 违规词 | 替换词 |
|--------|--------|
| XX人就是XX | 部分XX地区的朋友 |
| 男人都XX | 有些男生会XX |
| 底层人 | 普通人、打工人 |

**平台差异：** 小红书严控性别对立；抖音严控地域引战。

### 8. 平台违规操作类（中风险）

| 违规词 | 替换词 |
|--------|--------|
| 点赞送XX | 更多内容请关注 |
| 不看后悔 | 值得一看、推荐收藏 |
| 震惊 | 发现、注意到、有趣 |

## 三、特殊场景处理

### 场景1：擦边球词汇

想表达"性感"但又不想违规：
- 用视觉描述："优雅的曲线""有气质的穿搭"
- 用氛围词："高级感""魅力值拉满"
- 用间接表达："让人眼前一亮""吸引力十足"

### 场景2：行业专业术语

- 医美：不提疗效，只讲体验（"我的真实感受"）
- 金融：不谈收益，只谈认知（"财务规划思维"）
- 教育：不夸效果，只讲方法（"学习路径分享"）

### 场景3：追热点

- 避开政治敏感事件
- 不评论争议人物
- 不发表极端观点
- 只做客观分析，不带主观判断

## 四、核心原则

1. **宁严勿松**——不确定的词汇建议替换，避免风险
2. **不可绕过检测**——谐音、拆字、拼音绕过的方式平台能识别
3. **发之前过一遍**——每篇笔记发布前用敏感词检测过一遍
4. **人工复核**——AI检测后建议人工再确认一次
5. **规则会变**——平台规则会更新，定期关注最新政策

## 五、虚拟电商常见雷区

做虚拟电商特别容易踩的词：

| 场景 | 雷区词 | 安全替代 |
|------|--------|---------|
| 产品描述 | 教程/课程/培训 | 方法/指南/资料/工具包 |
| 收益承诺 | 日赚XX/月入XX | 分享经验/提升效率 |
| 导流 | 加微信/私信我 | 评论区互动/关注获取 |
| 夸大效果 | 保证/一定/100% | 帮助/辅助/大概率 |
