# 战略研究 Skill 包说明

## 文件说明

- `SKILL.md`：主入口，定义何时触发、怎么做、输出什么
- `reference.md`：详细判断口径与方法论抽取
- `examples.md`：常见任务示例
- `checklist.md`：执行检查清单

## 适合解决的问题

- 战略研究
- 战略设计
- 战略管理
- 战略目标拆解
- 战略落地执行
- 从战略推导组织、招聘、培养、产品、品牌、增长

## 建议使用方式

1. 先用 `SKILL.md` 判断任务属于哪类战略问题。
2. 再用 `reference.md` 补判断口径。
3. 需要快速交付时，参考 `examples.md` 的骨架。
4. 输出前，用 `checklist.md` 自检。
