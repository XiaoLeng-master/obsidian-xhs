# 战略研究参考规则

这份文件用于补充 `SKILL.md` 中没有展开的判断口径。

## 一、战略底盘

从现有资料里，适合沉淀为长期使用规则的底层原则主要有这几条：

- 用户主义：所有战略、产品、品牌、增长，先回到真实用户与真实需求。
- 长期主义：优先选择能长期积累、能形成壁垒的方向。
- 积累主义：技术、人才、流程、知识、品牌、用户都要持续积累。
- 不败思维：很多时候先追求活下来、站住、持续赢，而不是表面规模。
- 双驱动思维：既看长期能力建设，也看中短期业务变现。

如果用户要的是短期增长方案，也不要完全丢掉长期能力建设视角。

## 二、五看三定的展开口径

### 1. 看行业与趋势

重点看：

- 这个行业未来 3-5 年是不是还在变大
- 哪些技术、政策、人口、行为在改变
- 趋势变化会带来哪些新机会和旧机会消失

常见输出：

- 趋势判断
- 趋势对业务的机会/风险

### 2. 看市场与客户

重点看：

- 用户是谁
- 用户需求是否高频、刚性、长期
- 市场规模是否足够大
- 需求是集中还是分散

常见输出：

- 用户分层
- 需求分层
- 场景分层

### 3. 看竞争

重点看：

- 头部是谁
- 他们靠什么赢
- 他们在哪些地方已经强到不适合正面对打
- 哪些空白位、错配位、薄弱位可以切

常见输出：

- 竞争地图
- 差异化机会
- 避免正面冲突的策略

### 4. 看自己

重点看：

- 自己当前最强的能力是什么
- 哪些能力只是想象出来的，不是真实能力
- 哪些资源、团队、技术、品牌是现阶段真有的
- 能力边界由谁决定

补充规则：

- 团队的最大能力边界，往往由最核心的 3-5 人决定。
- 老板认知、核心团队认知，往往直接决定战略上限。

### 5. 看机会

战略机会点至少同时满足几项：

- 需求真实存在
- 市场足够大
- 方向能积累
- 自己有切入可能
- 能形成控制点或壁垒
- 团队有机会把它做成

如果只是“很热”“很新”“别人都在做”，不能直接判定为战略机会点。

### 6. 定控制点

控制点常见包括：

- 关键用户群
- 关键渠道
- 关键能力
- 关键技术
- 关键内容或品牌资产
- 关键数据或转化环节

一句话判断：

如果这个点失控，战略大概率跑不动，那它就是控制点。

### 7. 定目标

目标至少分 3 层：

- 战略目标
- 阶段目标
- 执行目标

避免只写大词，比如“做大做强”“成为行业第一”。

更好的写法是：

- 在什么时间
- 服务谁
- 做到什么规模/结果
- 靠什么路径实现

### 8. 定策略

策略不是愿望，而是赢法。

至少回答：

- 我们选择怎么赢
- 为什么这种打法适合我们
- 为什么不用另外几种打法

## 三、战略解码规则

战略解码的标准链路：

公司战略 -> 业务战略 -> 年度 BP -> 团队目标 -> 部门目标 -> 岗位目标 -> 个人动作

解码时必须补齐：

- 目标
- 动作
- 节点
- 指标
- 负责人

如果用户抱怨“团队不会拆目标”，优先检查：

- 战略目标是不是太空
- 中层是否达成共识
- 是否缺关键控制点
- 是否只有 KPI，没有关键动作

## 四、组织与人才规则

### 1. CEO/老大应该控制的内容

至少要覆盖：

- 战略方向
- 制度与架构
- 产品定义
- 技术方向
- 团队配置
- 财务与成本
- 执行进度与结果

如果一个老板自己补不齐，核心班子也要补齐。

### 2. 新业务核心团队组合

早期核心通常至少要有三类人：

- 搞技术的人
- 搞需求和产品的人
- 搞市场和增长的人

如果这三种能力缺一块，战略落地会明显失衡。

### 3. 团队组建的三条基本策略

- 定期能力评估
- 持续提比当前能力高 10% 的要求
- 持续引导能力外扩

### 4. 用人判断

可优先用这几组模型：

- 工作质量 x 工作效率
- 当前价值 x 未来潜力
- 阶段适配度
- 岗位适配度

高频判断提醒：

- 不是所有高潜都适合当前阶段
- 不是所有专业强的人都适合做管理
- 不是所有团队问题都是人的问题

### 5. 阶段不同，招聘与培养策略不同

可参考的基本倾向：

- 种子期、起步期：更依赖外部引入成熟中高级人才
- 爆发期：内部培养与外部招聘逐步平衡
- 稳定期：更强调内部培养和梯队建设

### 6. 员工发展视角

除了绩效，也要看员工是否感受到：

- 收入提升
- 学到东西
- 发展机会
- 状态与意义感

因为这直接影响组织稳定性与长期战斗力。

## 五、产品规则

### 1. 产品定义从哪里来

不是只看官方定义。

产品研究至少看三层：

- 官方定义
- 第三方分析定义
- 用户真实理解

新战略机会点和新产品创新点，很多时候藏在后两层。

### 2. 产品设计主线

从资料中提炼出的稳定主线是：

- 基于用户强需求设计商业模式
- 明确目标与使命
- 做功能设计
- 做功能结构图
- 做原型
- 做视觉
- 做开发与测试
- 上线运营
- 数据反馈后持续升级

### 3. 核心功能与核心流程

判断产品时，一定要回答：

- 核心功能是什么
- 核心流程是什么
- 哪些只是辅助功能

因为核心功能 + 核心流程，基本决定了这到底是什么产品。

### 4. UGD 视角

产品不能只看体验，还要看增长。

适合沉淀成固定规则的判断是：

- 更懂行业
- 更懂用户
- 更懂数据
- 更懂增长

如果一套产品方案无法说明如何促进业务增长，这套方案通常还不完整。

## 六、品牌与营销规则

### 1. 产品即品牌

对互联网产品来说，品牌很大一部分是在产品使用过程中建立的。

可沉淀为常用原则：

- 产品内传播是重点
- 产品外传播是辅助
- 用户在那里，品牌营销就在那里

### 2. 品牌定义不能只用官方口径

需要叠加两层：

- 官方想表达的价值
- 用户真实认同的价值点

如果两者偏差很大，优先用用户能听懂、能认同、能传播的话去重写表达。

### 3. 品牌营销 SOP

推荐按这条线组织：

分析研究 -> 品牌定义及策划 -> 物料生产 -> 渠道分发 -> 结果评估 -> 继续优化

### 4. 常见渠道与内容类型

渠道：

- 抖音
- 视频号
- 小红书
- 知乎
- 微博
- 公众号
- 新闻媒体
- 行业资讯站
- 社区站

物料：

- 长文
- 图文
- 视频
- 问答

## 七、增长与营收规则

### 1. AARRR 作为基础增长漏斗

至少要看：

- 拉新
- 激活
- 留存
- 付费
- 传播

不要只盯拉新，不看留存和付费。

### 2. PLG 适用判断

产品更适合 PLG 时，通常具备这些特征：

- 边际成本较低
- 上手较快
- 用户能直接感知价值
- 用户能影响购买决策
- 产品本身具备传播或扩张能力

### 3. 增长北极星指标

优先找三者交点：

- 商业目标
- 用户价值
- 战略选择

### 4. 营收与盈利模型

营收模型不只是“定个价格”。

至少要检查：

- SKU 类型
- 价格梯度
- SKU 数量
- 排序
- 文案
- 视觉与版式
- 赠送策略

很多时候付费转化差，不是流量问题，而是盈利设计太粗。

## 八、常见误区

- 只谈战略方向，不谈组织能力
- 只谈目标，不谈控制点
- 只谈产品功能，不谈用户与竞争
- 只谈品牌表达，不谈用户认同价值点
- 只谈拉新，不谈留存和付费
- 只谈招聘，不谈战略需要什么人
- 只谈培训，不谈业务结果和岗位要求
- 把“热点”误判成“机会点”

## 九、建议联动的现有 Skill

- 需要深度研究和对标：`通用（分析）`
- 需要组织、招聘、培养、评估：`团队与人才管理`
- 需要需求抓取与产品化：`用户调研-需求抓取-产品化落地`
- 需要正式方案文档：`通用（产品策划 PRD）`
- 需要把零散内容讲清楚：`通用（产品逻辑梳理）`
