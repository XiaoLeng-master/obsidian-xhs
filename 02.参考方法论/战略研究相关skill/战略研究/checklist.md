# 战略研究检查清单

## 一、开始前先检查

- [ ] 这次是公司级、业务级、项目级，还是品牌/增长级战略问题
- [ ] 当前业务阶段是否明确
- [ ] 时间周期是否明确
- [ ] 当前核心目标是否明确
- [ ] 当前资源约束是否明确
- [ ] 当前竞争环境是否大致明确

如果以上缺 2 项及以上，先追问，不要直接给完整结论。

## 二、五看检查

- [ ] 看了行业与趋势
- [ ] 看了市场与客户
- [ ] 看了竞争
- [ ] 看了自己
- [ ] 看了机会
- [ ] 最终明确了战略机会点
- [ ] 同时指出了“不该做什么”

## 三、三定检查

- [ ] 定了控制点
- [ ] 定了目标
- [ ] 定了策略
- [ ] 回答了“为什么这样打”
- [ ] 回答了“为什么不那样打”

## 四、战略解码检查

- [ ] 公司级目标已翻译到业务/团队层
- [ ] 关键项目已识别
- [ ] 关键岗位已识别
- [ ] 节点与负责人已明确
- [ ] 指标与检查方式已明确

## 五、组织与人才检查

- [ ] 是否回答了需要什么组织形态
- [ ] 是否回答了核心团队怎么配
- [ ] 是否回答了哪些岗位先招
- [ ] 是否回答了哪些人该培养
- [ ] 是否回答了评估、任用、发展路径

## 六、产品检查

- [ ] 是否定义了目标用户
- [ ] 是否定义了核心价值
- [ ] 是否区分核心功能和辅助功能
- [ ] 是否定义了核心流程
- [ ] 是否回答了先做什么、不做什么

## 七、品牌与增长检查

- [ ] 是否定义了品牌口径
- [ ] 是否识别了用户认同价值点
- [ ] 是否给出渠道与分发策略
- [ ] 是否明确增长杠杆
- [ ] 是否有关键指标或北极星指标

## 八、执行检查

- [ ] 是否有周/月/季度节奏
- [ ] 是否有监控指标
- [ ] 是否有偏差预警
- [ ] 是否有复盘机制

## 九、输出质量检查

- [ ] 结论是否前置
- [ ] 是否有明确取舍
- [ ] 是否避免“都重要”
- [ ] 是否避免空泛大词
- [ ] 是否把不确定内容标成假设
- [ ] 是否给出下一步动作
