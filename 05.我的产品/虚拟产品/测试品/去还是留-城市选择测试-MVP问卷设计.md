# 「去还是留？城市选择测试」MVP问卷设计

> 版本：MVP v1.0
> 题目数量：35题（预留5题删减空间，实际MVP可用30题）
> 5个维度：职业发展 / 家庭约束 / 情感归属 / 财务现实 / 内心倾向
> 每题4个选项 + 权重分值

---

## 设计原则

1. **不评判**——题目不给用户施加压力（不暗示"留是对的"或"走是对的"）
2. **说人话**——选项是用户心里真实会想的话，不是学术量表
3. **挖真话**——选项设计引导用户暴露真实想法，而非"应该"的想法
4. **覆盖三类人**——每道题让深漂、异地恋、独生子女都能找到自己的影子

## 计分规则

每题选项后有分值标记：
- **+2 留**：强烈倾向留在大城市
- **+1 留**：倾向留在大城市
- **0**：中立
- **+1 走**：倾向回老家
- **+2 走**：强烈倾向回老家

总分范围：大致 -70 到 +70

### 结果分级（建议）

| 总分区间 | 结果类型 | 解读方向 |
|:--:|------|------|
| +30 ~ +70 | **扎根型** | 你内心和现实条件都支持你留在大城市。你的焦虑可能只是暂时的疲惫，不是真的想走。 |
| +10 ~ +29 | **偏向留** | 你更适合留，但有一些因素在拉扯你。建议先解决这些拉扯因素（比如异地、父母健康），再做最终决定。 |
| -9 ~ +9 | **摇摆型** | 你是最需要这个测试的人。你的留和走几乎势均力敌，建议按"分阶段路径"来规划——先搞清楚你最在意什么。 |
| -10 ~ -29 | **偏向回** | 你内心和条件都傾向回老家/二线，但还有放不下的事。建议制定一个"回去"的时间表和条件。 |
| -30 ~ -70 | **回归型** | 你已经知道答案了，只是需要有人帮你说出来。回老家不是失败，是另一种选择。 |
