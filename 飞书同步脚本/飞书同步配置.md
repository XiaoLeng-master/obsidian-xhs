# 飞书碎片同步配置

## 功能
你在飞书机器人对话框里发的消息（文字/语音转文字） → 自动同步到 Obsidian 的 `04.我的输入/inbox/`，按日期归档为 markdown 笔记。

两个脚本，配合使用：
- `sync-feishu-ideas.ps1` — 每天定时自动跑（拉最近7天的新消息）
- `sync-feishu-ideas-now.ps1` — 双击立即跑（拉全部历史消息，首次使用或想补全时用）

## 使用场景
走路想到一个选题灵感 → 打开飞书发给机器人 → 回到电脑自动就在 Obsidian 里了

---

## 前置条件

按顺序完成以下3步，才能用同步脚本：

**① 安装 lark-cli**

打开 PowerShell，运行：
```
npm install -g @larksuite/cli
```
> 前提是你已经装好了 Node.js。没装的话先去 https://nodejs.org 下载 LTS 版本安装。

**② 创建飞书应用 + 开启机器人**

1. 打开 https://open.feishu.cn/app → 创建企业自建应用
2. 在应用的「添加应用能力」里，开启 **机器人** 能力
3. 在「权限管理」里，搜索并开通以下权限：
   - `im:message` — 获取与发送消息
   - `im:chat:readonly` — 获取群信息
4. 发布应用（创建一个版本 → 申请上线）
5. 记录你的 `app_id` 和 `app_secret`

**③ 初始化 lark-cli 配置**

```
lark-cli config init
```
按提示填入 `app_id` 和 `app_secret`，完成后验证一下：
```
lark-cli im +chat-list --as bot
```
如果能返回结果（哪怕是空列表），说明配置成功。

> 遇到问题直接跟AI说"帮我配置 lark-cli"，它会一步步排查。

## 配置步骤

### 第1步：获取你的 CHAT_ID

CHAT_ID 是你和飞书机器人的对话ID，每个人不一样。

1. 先在飞书里找到你的机器人，随便发一条消息
2. 打开终端（PowerShell），运行：
   ```
   lark-cli im +chat-list --as bot
   ```
3. 在返回结果中找到你和机器人的对话，复制 `chat_id` 字段的值
   - 格式类似 `oc_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

> 💡 如果返回多个对话，找 `chat_type` 为 `p2p`（单聊）的那个

### 第2步：填入脚本

打开这两个文件，找到第18行的 `$CHAT_ID`，把占位符替换成你的：

**文件1：** `飞书同步脚本/sync-feishu-ideas.ps1`
**文件2：** `飞书同步脚本/sync-feishu-ideas-now.ps1`

```powershell
# 把这行：
$CHAT_ID = "你的飞书机器人CHAT_ID"
# 改成（引号保留）：
$CHAT_ID = "oc_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

> ⚠️ 只改 CHAT_ID 这一行，其他不要动。脚本会自动找到你的 vault 和 `04.我的输入/inbox/` 目录。

### 第3步：首次运行（补全历史消息）

右键 `sync-feishu-ideas-now.ps1` → **用 PowerShell 运行**

会把你之前发给机器人的所有消息全部同步过来，按日期生成 `yyyy-MM-dd.md` 文件到 `04.我的输入/inbox/`

### 第4步：设置每天自动同步（可选）

让电脑每天早上9点自动跑同步脚本：

1. 按 `Win + R`，输入 `taskschd.msc`，回车打开任务计划程序
2. 右侧点 **"创建基本任务"**
3. 名称填：`飞书碎片同步`
4. 触发器选：**每天**，时间设 `09:00`
5. 操作选：**启动程序**
   - 程序：`powershell.exe`
   - 参数：`-ExecutionPolicy Bypass -File "你的vault完整路径\飞书同步脚本\sync-feishu-ideas.ps1"`
   - 例如：`-ExecutionPolicy Bypass -File "D:\MyVault\飞书同步脚本\sync-feishu-ideas.ps1"`
6. 勾选 **"当点击完成时打开属性对话框"**，在条件里取消 **"只有在计算机使用交流电源时才启动"**

> 💡 也可以跟AI说"帮我设置飞书同步的定时任务"，它会帮你用命令行一键创建。

### 第5步（可选）：创建桌面快捷方式

方便随时手动同步：

1. 右键桌面 → 新建 → 快捷方式
2. 目标填：`powershell.exe -ExecutionPolicy Bypass -File "你的vault完整路径\飞书同步脚本\sync-feishu-ideas-now.ps1"`
3. 名称填：`同步飞书碎片`

以后双击就能跑。

## 日志和排错

- 运行日志在 `飞书同步脚本/sync-feishu-ideas.log`
- 已同步的消息ID记录在 `.synced-ids`，不会重复同步
- 遇到问题直接跟AI说"帮我排查飞书同步脚本问题"，把日志内容贴进去

## 注意事项

- 所有凭证（app_id、app_secret等）只存在你本地，不要分享给别人
- 飞书应用需要给对应的权限（读写多维表格、接收消息等）
- 遇到问题直接跟AI说"帮我排查飞书配置问题"，它会引导你一步步检查
