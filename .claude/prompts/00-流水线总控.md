# 流水线总控：写笔记前4步弹药准备

> 这条流水线把一个产品的"弹药准备"拆成 4 个 AI 节点。每次为一个新产品跑一次，产出存入 `03.我的弹药库/`。

## 流水线结构

```
输入: 产品名称 + 品类 + 目标平台
  ↓
节点1: 客户画像生成 → 输出: 3个精准客户画像
  ↓
节点2: 关键词矩阵扩展 → 输出: 关键词矩阵（标题词/正文词/封面词/商品词）
  ↓
节点3: 爆款结构分析 → 输出: 对标笔记结构拆解 + 可复用模板
  ↓
节点4: 情绪洞察 → 输出: 主打情绪 + 情绪句式 + 场景锚点
  ↓
输出: 弹药库速查卡（汇总4节点产出）
```

## 人工判断点

每个节点完成后，你只需要做一件事：**看一眼输出，确认"对/不对/改一下"**。

- 节点1：画像是否精准？是否具体到能"看见一个人"？
- 节点2：关键词是否真的有人在搜？
- 节点3：对标结构是否可复用？
- 节点4：情绪是否真的能打动人？

## 使用方法

从节点1开始，把上一个节点的输出复制到下一个节点的"输入材料"中。
或者在一条对话里依次输入 4 个节点的 prompt，让 AI 串行执行。
