# 流水线：商品笔记写作

> 输入弹药库速查卡，输出一篇可直接发布的商品笔记。
> 每个节点 AI 产出后，你只需要做一次人工判断。

## 流水线结构

```
输入: 弹药库速查卡（客户画像+关键词+对标模板+情绪策略）
  ↓
节点N1: 选题生成 → 输出: 5个选题方向 + 爆款概率评估
  ↓ 人工判断：选1个
节点N2: 初稿生成 → 输出: 完整笔记正文 + 3个备选标题
  ↓ 人工判断：改掉"不像你说的话"的部分
节点N3: 封面标题优化 → 输出: 封面文案 + 最终标题 + 标签
  ↓ 人工判断：封面能不能抓住人？
节点N4: 质检 → 输出: 敏感词检测 + 风险点 + 修改建议
  ↓ 人工判断：是否可发布？
输出: 一篇经过质检、可直接发布的商品笔记
```

## 关键原则

1. **AI 生成 80%，人打磨 20%**——但打磨的是最关键的 20%（真实感、边界感、个人味道）
2. **每篇笔记标注数据表现**——曝光/点击/互动/出单，形成反馈闭环
3. **爆了立刻复制模板**——同一结构换产品继续发
4. **没爆看数据**——是封面问题改封面，是标题问题改标题，别大改正文
