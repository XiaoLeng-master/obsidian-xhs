# 碎片分层

> 你的碎片想法先过安全筛，再决定能不能见人。

## 前置条件

执行前**必须先读取** `CLAUDE.md`，获取：
- 身份信息（IP定位、目标用户、敏感地带）→ 用于🟢🟡🔴分层判断

---

## 🎯 功能概述

一个 **聚类 + 过滤 + 选题** 三合一的碎片处理器：

```
碎片输入 → 主题聚类 → IP安全分层（🟢🟡🔴） → 改写建议 → 可发展选题 → 存档
```

解决的问题：
1. 碎片想法散落各处，没有归类
2. 有些想法观点好但直接发会暴露真实状态，需要包装
3. 有些想法绝对不能发，但没人帮你拦

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `碎片内容` | ✅ 是 | 任意形式：多条想法、飞书笔记、语音转文字、粘贴的零散句子 | - |
| `日期` | ❌ 否 | digest 对应日期 | 当天日期 |
| `原始来源` | ❌ 否 | 碎片来自哪里（飞书/随手记/对话等） | auto-digest |

## 🔄 工作流程

### Step 1：碎片清洗

接收原始内容后：
- 逐条拆分（按换行/序号/语义断句）
- 去除无意义的口语填充（"嗯"、"那个"、"就是说"）
- 保留原始表达的核心意思，不改变语义
- 统计碎片总数

### Step 2：主题聚类

将碎片按语义相近度归类，每个主题簇：
- 拟一个 **主题标题**（简短有力，不超过15字）
- 下挂该主题的所有碎片条目
- 如果碎片之间有逻辑递进关系，按逻辑排序而非原始顺序

**聚类原则：**
- 主题数量一般 3-7 个，不要过碎
- 单条碎片如果足够独立且有力，可以独立成一个主题
- 同一条碎片只归入一个最相关的主题

### Step 3：IP安全分层（核心步骤）

对每条碎片打标：

| 标记 | 判断标准 | 处理方式 |
|------|----------|----------|
| 🟢 直接发 | 纯方法论/金句/认知输出，读者看到的是你的水平，看不到你的处境 | 原文或微调即可用于公众号/小红书 |
| 🟡 换主语发 | 观点好但原文像自我对话/暴露正在经历的状态 | 必须给出具体改写方向（换成什么视角、怎么换） |
| 🔴 不发 | 暴露焦虑/矛盾/底牌/团队内部问题/对合作方的负面评价 | 标注原因，建议存入经验沉淀或仅自己消化 |

**分层判断的底层逻辑——读者看完会怎么想：**

问自己三个问题：
1. **读者看完觉得你牛不牛？** → 牛 = 🟢，不确定 = 🟡，觉得你在诉苦/迷茫 = 🔴
2. **竞争对手看到能拿来攻击你吗？** → 能 = 🔴
3. **学员看到会不会动摇信任？** → 会 = 🔴，微调后不会 = 🟡

**高危关键词自动触发🔴检查：**
- 情绪类：焦虑、迷茫、不知道怎么办、扛不住、累了、算了
- 关系类：闹矛盾、吵架、冷战、分开、不合作了
- 业务类：亏了、没单、做不下去、要不要换赛道
- 竞对类：对具体人/公司的负面评价

**🟡 换主语的常用手法：**

| 原文视角 | 改写方向 | 示例 |
|----------|----------|------|
| "我现在很焦虑" | 过来人视角 | "我去年踩过一个坑——焦虑的时候做的决策，事后全要推翻" |
| "我不知道该不该..." | 输出者视角 | "我给学员的建议是：不确定的时候，先做能验证的最小动作" |
| "我跟XX闹矛盾了" | 方法论视角 | "合伙人关系里最重要的一条：不上情绪，把人当资源" |
| "目标定太高了" | 观察者视角 | "我见过太多创业者犯同一个错——目标定得热血沸腾，月底焦虑到变形" |

### Step 4：每个主题簇写总结

每个主题下方写 1-3 句话的串联总结：
- 说清楚这几条碎片串在一起的逻辑是什么
- 不是复述，是提炼——"这三条本质上在说同一件事：xxx"

### Step 5：可发展选题提炼

从所有 🟢 和 🟡 碎片中，挑出 2-5 个有潜力发展成完整内容的选题：

每个选题包含：
- **选题标题**（一句话，带情绪钩子）
- **适合平台**（公众号深度文/小红书图文/短视频口播）
- **发展方向**（2-3句话说清楚怎么展开）
- **注意事项**（如果是🟡来源，提醒换主语的要点）

**选题优先级判断：**
- 有反常识观点的 > 纯正确的废话
- 有具体数据/案例支撑的 > 纯观点
- 能引发讨论/争议的 > 单向输出
- 命中目标人群痛点的（副业焦虑/经济独立/方向迷茫）优先

### Step 6：生成 digest 文件

**输出路径：** `04.我的输入/碎片整理/{日期}-digest.md`

**文件模板：**

```markdown
---
date: {日期}
type: digest
source: {来源}
fragments: {碎片总数}
---

# {日期} 今日思考

> 基于当天 {碎片数} 条碎片自动整理，原始记录见 [[{日期}]]

## {主题1标题}

{主题总结}

- 🟢/🟡/🔴 碎片内容1
- 🟢/🟡/🔴 碎片内容2

{🟡条目的改写建议，用独立段落写在对应碎片下方}
{🔴条目的不发原因，用独立段落写在对应碎片下方}

## {主题2标题}

...（同上结构）

---

## 发布分层标记说明

| 标记 | 含义 | 处理方式 |
|------|------|----------|
| 🟢 直接发 | 纯方法论/金句，不暴露个人状态 | 原文或微调即可用于公众号/小红书 |
| 🟡 换主语发 | 观点好但原文像自我对话，会露状态 | 换成"我观察到/我跟学员说/很多创业者..."再发 |
| 🔴 不发 | 暴露焦虑、矛盾、底牌 | 只留给自己，或存入经验沉淀 |

---

## 可发展的选题

1. 🟢/🟡 **"选题标题"** → 适合平台。发展方向描述。
2. ...
```

### Step 7：输出确认

生成文件后，给用户一个简要汇报：
- 共处理 X 条碎片，归为 X 个主题
- 🟢 X 条 / 🟡 X 条 / 🔴 X 条
- 提炼 X 个可发展选题
- 文件已存至 [[{碎片digest路径}/{日期}-digest.md]]

## ⚠️ 注意事项

1. **不编造**：碎片里没有的内容不要添加，聚类和分层只基于原始输入
2. **不删减**：每条碎片都必须出现在最终 digest 里，即使是🔴也要保留（标注不发原因）
3. **数据原样**：碎片中的具体数字、金额、比例不修改
4. **🟡必须给具体改写方向**：不能只说"换个主语"就完了，要写清楚换成什么视角、示例怎么改
5. **🔴必须给原因**：不能只打标不解释，要说清楚"为什么不能发"
6. **读取 CLAUDE.md 了解身份**：分层判断需要知道用户的 IP 定位、业务现状、目标人群，才能准确判断什么该发什么不该发
