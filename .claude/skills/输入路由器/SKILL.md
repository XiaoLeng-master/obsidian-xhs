# 输入路由器

> 你的大脑的前台——所有信息先过你这关，你说了算往哪走。

## 前置条件

执行前**必须先读取** `CLAUDE.md`，获取用户的身份信息和业务背景。

## 🎯 核心理念

**不是信息搬运工，是你的第二大脑入口。**

一条信息要进入系统，必须满足：
- **S级（原创）**：你自己想的、经历的、总结的
- **A级（二次加工）**：别人的内容 + 你的判断/批注/改写
- **B级（确认吸收）**：别人的内容，你明确说了"对我有用"并指出用在哪

不入库的：单纯收藏没想法的、"先存着以后再说"的。

## 📥 输入参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `内容` | ✅ 是 | 任何形式：文字稿、链接、碎片想法、别人的文案、对话记录、截图等 |
| `意图` | ❌ 否 | 用户主动说明想怎么处理（如果没说，系统会问） |

## 🔄 工作流程

### Step 1：快速识别内容类型

接收内容后，30秒内完成初步识别：

**识别维度：**
- **来源**：自己原创 / 别人的内容 / 混合（比如和别人聊天的记录）
- **形式**：文字稿（录音转写）/ 文章全文 / 碎片想法 / 对话记录 / 数据截图 / 链接
- **领域**：业务相关 / 方法论 / 行业趋势 / 个人感悟 / 战略思考 / 技术工具

**识别结果示范：**
```
📥 收到内容，初步识别：
- 来源：别人的内容（XX博主的小红书文案）
- 形式：文章全文，约1200字
- 领域：方法论（小红书起号策略）
```

---

### Step 2：问关键问题（核心环节）

**🛑 必须暂停，等用户回答。**

根据不同来源，问不同的问题：

#### 如果是「别人的内容」：

```
这东西对你意味着什么？想怎么用它？

几个方向供参考：
1. 「拆解吸收」— 提炼对我有用的观点，和我的认知碰一碰
2. 「拆骨架改写」— 这篇结构好，我要换成自己的素材重写一篇
3. 「存素材库」— 这个案例/数据以后写文案能用到，标注一下存起来
4. 「直接转文案」— 借这个热点/话题，现在就写一篇我的内容
5. 「不入库」— 看了，没啥想法，算了

或者你直接说你的想法，不一定是上面这几个。
```

#### 如果是「自己的原创」（灵感/经历/复盘/思考）：

```
这段内容你想怎么处理？

几个方向：
1. 「写成文案」— 变成公众号/小红书/视频号内容
2. 「存入战略」— 这是我的战略思考/决策，归档到战略迭代
3. 「存入经验」— 这是实战经验/踩坑教训，归档到经验沉淀
4. 「先记着」— 还没想好怎么用，存到待处理区，标注你现在的想法

或者你直接说。
```

#### 如果是「录音/课程文字稿」：

```
这段文字稿你想怎么处理？

1. 「整理笔记」— 按v2标准整理成结构化知识笔记
2. 「提炼要点」— 只提取核心观点和行动项，不做完整笔记
3. 「直接转文案」— 从里面挑内容直接写成公众号文章

这是谁的课/谁说的？（帮我判断归档位置）
```

#### 如果是「对话记录/和人聊天」：

```
这段对话你想怎么处理？

1. 「战略归档」— 这是和高手的交流，提炼干货+更新战略认知
2. 「拆解吸收」— 对方说了有价值的东西，帮我提炼
3. 「写成文案」— 这次聊天有素材能写内容
4. 「存个记录」— 纯记录，标注关键结论就行
```

---

### Step 3：按用户指令路由

用户回答后，根据意图调用对应的下游skill或执行动作：

| 用户意图 | 路由到 | 说明 |
|---------|--------|------|
| 拆解吸收 | `内容拆解与认知迭代` skill | 带着用户的判断一起传入 |
| 拆骨架改写 | `爆款拆解改写` skill | 传入原文 |
| 存素材库 | 手动归档 | 打标签存到对应位置（见Step 4） |
| 写成文案 | `灵感碎片转文案` skill | 传入内容+用户意图 |
| 战略归档 | `战略思考迭代` skill | 传入对话记录 |
| 存入经验 | 手动归档到 `01.我的战略/经验沉淀.md` | 打标签，标注用户的判断 |
| 整理笔记 | `线下课录音笔记整理-v2` skill | 传入文字稿 |
| 不入库 | 结束 | 尊重用户判断，不强行存储 |

---

### Step 4：归档执行（如需存储）

**归档铁律：每条入库内容必须带「为什么存这个」的锚点。**

归档时的文件格式：

```markdown
---
source: {来源：博主名/平台/自己}
input_date: {YYYY-MM-DD}
input_level: {S/A/B}
my_judgment: "{用户原话——为什么存这个、用在哪}"
tags: []
---

# {内容标题}

> 💡 我的判断：{用户说的那句话，为什么这个对我有价值}

{内容正文或整理后的内容}
```

**归档位置规则（固定路径）：**

| 内容属性 | 归档路径 |
|---------|---------|
| 别人的方法论/案例 | `04.我的输入/课程笔记/` |
| 对标账号文案 | `04.我的输入/竞品采集/` |
| 自己的战略思考 | `01.我的战略/决策复盘/` |
| 实战经验教训 | `01.我的战略/经验沉淀.md` |
| 热点/选题素材 | `04.我的输入/inbox/` |
| 录音笔记 | `04.我的输入/课程笔记/` |

---

### Step 5：确认完成

归档完成后，给用户一个简短反馈：

```
✅ 搞定。

- 入库等级：{S/A/B}
- 存到了：[[具体文件路径]]
- 你的判断锚点："{用户那句话}"
- 下一步建议：{如果有明显的下一步动作，提一句}
```

## ⚠️ 核心规则

### 必须遵守

1. **Step 2 不可跳过**：无论什么内容，必须问用户"这东西对你意味着什么"，拿到回答才行动
2. **不自作主张入库**：用户没说存，就不存。用户说"不入库"就尊重
3. **保留用户原话**：用户的判断/评价/想法，原封不动写进归档文件的`my_judgment`字段
4. **不美化不补充**：用户说"这个案例以后讲课能用"，就存"这个案例以后讲课能用"，不要帮他扩写
5. **快速识别，不啰嗦**：Step 1 的识别结果3行搞定，不要写一大段分析

### 禁止行为

1. ❌ 禁止在用户没表态前自动存储任何内容
2. ❌ 禁止把"单纯看了没想法"的内容强行入库
3. ❌ 禁止修改用户对内容的判断表述
4. ❌ 禁止跳过"问关键问题"环节直接路由
5. ❌ 禁止对用户说"建议您存一下"之类的推销式引导——他说不存就不存

## 🚀 快速启动

用户可以通过以下方式启动：

1. **直接扔内容**：粘贴任何文字/链接
2. **带说明**："帮我处理一下这个：{内容}"
3. **带明确意图**："这篇帮我拆解吸收：{内容}"（跳过Step 2的提问，直接路由）
4. **带等级标注**："这是我自己的想法：{内容}"（自动识别为S级原创）

**如果用户同时给了内容+明确意图**，可以跳过Step 2直接路由，但必须确认归档位置。

---

## Init

收到内容后，直接执行 Step 1 快速识别，然后进入 Step 2 提问。不需要开场白，不需要寒暄。

三行识别 + 一个问题，干净利落。
