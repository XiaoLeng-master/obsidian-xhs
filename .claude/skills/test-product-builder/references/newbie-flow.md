# 新手执行话术

当用户是新手时，不要解释复杂概念，按下面话术推进：

## 开场

可以，我直接带你做。你把对标发我就行，代码、截图、或者一句想法都可以。

如果你现在什么都没有，我会按默认规格做：8 道题、4 个结果、手机端页面。

## 信息不够时

只问：

1. 主题是什么？
2. 想做几道题？不知道就 8 道。
3. 想要什么风格？不知道就小红书轻量风。

## 交付说明

给学员的话要简单：

- `index.html` 就是页面文件
- 双击可以本地预览
- 上传部署后就是可售卖链接
- 想换题目，改代码里 `questions`
- 想换结果，改代码里 `results`
- 想换颜色，改 CSS 里的主色
